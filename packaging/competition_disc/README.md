# Osteo Vision 比赛光盘运行包

本目录的唯一用户启动入口为根目录 `Osteo Vision Platform.exe`。双击后启动独立 Windows 桌面应用窗口，无需浏览器、网址、Node.js、Conda、Python 或网络连接。

`resources`、`locales` 等相邻目录属于应用运行时组成部分，刻录和复制时必须与 `Osteo Vision Platform.exe` 保持同级。它们提供受管 API、界面资源、模型 checkpoint、FFmpeg、严格比赛配置、CUDA 运行时及最小公开演示数据；用户无需手动启动其中任何文件。

## 目标电脑

- Windows 10 或 Windows 11，64 位。
- 可写入的用户目录。病例记录、上传数据、分析证据和日志写入当前用户的应用数据目录，因此应用可从只读光盘启动。
- 导入 JPEG/MP4 和生成证据所需的本地剩余空间。
- 可选 NVIDIA GPU 与兼容驱动。应用启动时探测 CUDA；可用时使用 GPU，加速条件不满足时自动走 CPU 路径并在桌面窗口显示状态。

应用使用严格比赛配置，主输入支持官方 JPEG 图像与 MP4 视频。官方设备技术文档确认 3840x2160 4K 影像以及 USB3.0 存储的 JPEG、MP4 格式。

## 内置演示

运行包内置一段 OFDVDnet 公开三视图荧光代理 MP4、四张通道预览图及 D024 公开下颌表面参考，可离线展示 MP4 导入、白光/荧光/设备叠加分离、双通道会话、关键帧人工标注与 L0 三维参考。OFDVDnet 为鸡腿荧光手术代理，D024 为公开 CBCT 下颌参考；两者均不代表真实术中 ICG 颌骨骨髓炎病例。

## 光盘使用

1. 使用 ISO/UDF 等保留长 Windows 文件名的文件系统刻录完整目录。
2. 在目标电脑打开光盘，双击 `Osteo Vision Platform.exe`。
3. 等待桌面应用窗口显示。顶部运行状态会显示已选 GPU，或 CPU 降级原因。
4. 需要完整性记录时，以 PowerShell 执行 `verify_release.ps1`。

根目录附带 `Osteo_Vision_r28_使用说明.docx` 与 `Osteo_Vision_r28_使用说明.pdf`，文档配有真实桌面测试截图，可在现场演示前查阅。

从光盘可直接启动。将完整目录复制到本机磁盘可降低 4K MP4 分析中的光驱读取压力。

## 发布校验

`verify_release.ps1` 校验发布清单、关键启动文件、文件长度和 SHA256，不会写入或修改运行包。校验耗时由光驱读取速度决定。

## 介质容量

构建脚本记录实际字节数，并按所选容量阻断超限发布。含 CUDA 的 PyTorch 运行时体积较大，默认按 8.5 GB 上限构建；700 MB CD 与单层 4.7 GB DVD 容量不足。

## 医学边界

平台输出用于医生复核的研发验证，不提供自动临床诊断，也不替代医生判断。
