# 患者条件分割公开数据缺口审计

审计日期：2026-07-18

## 结论

本轮确认了三套同时提供患者级临床变量和三维分割标注的数据来源。HCC-TACE-Seg 与 NSCLC-Radiomics 可作为开放代理数据；Head-Neck-Radiomics-HN1 的解剖区域更接近本项目，影像受 NIH 受控访问政策约束。本轮只下载 1.49 MB 的来源页面、临床表、下载清单和清单摘要，没有启动大体积影像下载。

当前仍缺少一套可直接公开获取的联合目标域数据，所需内容包括颌骨骨髓炎或坏死骨术中白光/ICG 影像、年龄、性别、基础病、用药、炎症与血液指标、医生复核骨面和像素级坏死/过渡/活骨标注。患者条件产生空间变化的能力继续维持研发验证状态。

## 数据价值

- `D072 HCC-TACE-Seg`：105 例多期增强 CT，提供临床复核的肝脏、肿瘤和血管 DICOM SEG；临床表含年龄、肝炎状态、AFP、分期、化疗和结局。适合联调临床变量、缺失值、患者级分组和分割条件化。
- `D077 NSCLC-Radiomics`：422 例胸部 CT，提供放射肿瘤科医生勾画的 GTV、RTSTRUCT 与 SEG；临床表含年龄、性别、TNM、组织学和生存。适合年龄/性别条件化和亚组审计工程。
- `D078 Head-Neck-Radiomics-HN1`：137 例头颈肿瘤，临床表含年龄、生物学性别、ECOG、HPV/p16、治疗前血红蛋白和治疗结局，影像带肿瘤体积标注。影像访问需要 NIH 受控数据批准，当前只保存公开元数据。

## 使用边界

三个数据集均设为 `target_domain_flag=false` 和 `training_eligible=false`。完成许可复核、内容质检、患者标识联接验证和任务准入后，开放代理数据可进入结构与消融实验。所有结果只能支持工程可运行性、临床数据契约和安全回退验证。

目标域空间效应的启用仍需真实颌骨骨髓炎病例，至少包含成对影像、临床变量、可信医生像素标注、患者/机构/时间独立测试集、概率校准和亚组无伤害审计。
