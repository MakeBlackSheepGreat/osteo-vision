# 数据清单与本地产物边界

本目录在 Git 中只保存公开数据的来源清单、下载收据、许可说明、校验记录、来源页面快照和必要的小型结构化元数据。原始影像、视频、模型输入、派生数据、物化样本和训练缓存均留在本机，并由 `.gitignore` 隔离。

## 版本控制边界

- `raw/`：下载的原始数据，不进入 Git。
- `derived/`：预处理、伪标注、训练和评估派生数据，不进入 Git。
- `materialized/`：从远程包或归档中选择性物化的数据，不进入 Git。
- `metadata/`：只保留来源核验所需的小型公开元数据；大型补充材料继续留在本机。
- 候选目录根部的 `manifest.json`、`manifest.csv`、下载收据和 `README`：作为可追溯证据进入 Git。

部分历史清单的 `local_path` 字段记录生成时的本机绝对路径，用于校验本地文件和 SHA256。该字段不表示数据文件已进入版本库，也不能作为跨机器固定路径；跨机器使用时应依据同条记录的 `relative_path` 或重新生成本地清单。

## 许可与医学边界

数据与来源元数据继续受各自上游许可约束，不随本仓库代码许可重新授权。所有公开数据均按清单记录的 `target_domain_flag`、`training_eligible` 和 `review_state` 执行准入；公开异域、代理或近似数据不能作为颌骨骨髓炎术中临床性能证据。任何真实医院数据、患者上传、病例数据库和医生标注均不得写入本目录或提交到 Git。
