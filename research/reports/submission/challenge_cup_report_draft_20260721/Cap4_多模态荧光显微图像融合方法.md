### 4.1.2 医院自有设备边界

当前医生合作单位为绵阳市第三人民医院头颈部颌面甲状腺科。现场设备为医院自有设备，与成都赛题方显微镜属于两套独立设备，可导出 JPG 与 AVI，并提供黑白荧光与伪彩显示模式。医院设备的格式、显示模式、参数与接口不得推定为赛题方设备能力；两套设备的资料、样本、接口与验证结果必须分别记录设备来源、准确型号、固件版本与采集配置。医院 AVI 文件通过受控转码流程转为 MP4，保留原始 AVI、SHA256、编解码参数、转码日志以及原始文件到 MP4 的对应关系。

### 4.1.3 通过清单调整以适配不同场景

平台软件保持设备解耦，倍率、工作距离、相机标定、坐标变换与位姿记录通过离线清单或人工元数据接入，不依赖企业私有接口。同一融合链可在不同放大倍率与工作距离下复用，仅需通过清单调整以下派生量：

- 单位像素对应的物理尺寸（由放大倍率与工作距离共同决定）；
- 视场直径（14–190 mm 范围内随倍率变化）；
- 配准搜索上限（按图像长边比例换算）；
- ROI 量化时的物理面积换算系数。

涉及倍率、工作距离、同步、配准等字段时，平台支持文件元数据、人工录入或离线清单三种接入方式；任一字段缺失时，相关派生量标注为"待复核"，融合链仍可输出图像级证据，物理量化结果保持不可用状态。

## 4.2 图像配准与融合

### 4.2.1 传统方法回顾

多模态医学图像配准的传统方法主要分为三类：

| 类别 | 代表方法 | 特点 | 在本场景下的局限 |
| --- | --- | --- | --- |
| 特征点法 | SIFT / SURF / ORB + RANSAC | 对纹理丰富场景鲁棒 | 荧光图像纹理弱、特征点稀疏，常出现匹配失败 |
| 灰度法 | 互信息、归一化互相关（NCC） | 对强度差异较鲁棒 | 计算量大，对大位移敏感，4K 图像耗时高 |
| 频域法 | 相位相关（phase correlation） | 仅估计平移，计算高效 | 仅限平移模型，旋转/形变需另外处理 |
| 简单叠加 | 直接 Alpha 混合 | 实现简单 | 未配准即叠加会产生重影，影响边界判读 |

颌骨骨髓炎术中白光与 ICG 荧光图像可由同一光路获得，但镜头倍率切换、局部遮挡、组织表面起伏和通道响应差异仍会产生残余局部形变。本项目以相位相关法作为平移基线，叠加分块相位测量、RANSAC 相似变换和有界二次局部残差场，再进入背景扣除、归一化、伪彩与增强链路；每个局部形变场均经过响应、幅度和残差改善门控，失败时保留最近可信全局变换或回退到全局仿射结果。

### 4.2.2 我们的方法：多通道融合链

白光与荧光双通道融合模块实现十步融合链，默认采用绿色调色板与自适应多尺度配准。配准器在 0.5 倍和 1.0 倍尺度运行边缘域相位相关，使用 3×4 分块的中位数与 MAD 剔除遮挡区域；全局证据不足时启用 ORB + RANSAC 相似变换候选。所有候选经过响应、相关质量、位移、尺度和有限矩阵安全门，再将通过门控的变换应用到 4K 原图。完整融合链依次包含：文件签名解码、双线性重采样尺寸对齐、百分位背景扣除、自适应多尺度配准、百分位鲁棒归一化、GPU 伪彩映射、GPU Alpha 混合、增强、ROI 与全图量化、色标与结构化报告输出。

![Fig 4-1 白光与荧光双通道融合及三通道质控](assets/fig_04_01_fusion_pipeline.png)

*Fig 4-1 双通道融合链整体融合与质控架构。设备叠加图用于显示和质控核对，模型输入保持原彩图与原始荧光图。*

#### 4.2.2.1 结构上的优势

1. **背景扣除先于配准**：百分位基底扣除在配准前进行，可减少荧光通道暗电流与背景散射对相位相关响应的干扰。
2. **配准-归一化解耦**：几何配准与强度归一化分别处理空间与强度域，避免归一化破坏相位相关所需的灰度统计。
3. **伪彩与混合分离**：伪彩映射与 Alpha 混合独立配置，医生可根据术式偏好切换绿色/琥珀/品红调色板而不影响配准与量化结果。
4. **量化-报告一体化**：量化与报告输出在同一调用中完成，输出结构化数据、Markdown 报告、色标图与归一化图，便于证据包归档与复核。

#### 4.2.2.2 性能上的优势

| 维度 | 传统简单叠加 | 本项目融合链 |
| --- | --- | --- |
| 配准 | 无 | 多尺度相位相关 + 遮挡鲁棒分块 + ORB/RANSAC 后备，含失败降级 |
| 背景 | 不扣除 | 百分位基底扣除 |
| 归一化 | 线性拉伸 | 百分位鲁棒归一化 |
| 增强 | 无 | 高斯降噪 + CLAHE 局部对比度增强 |
| 质量门控 | 无 | 配准响应、平移幅度、几何一致性三重门控 |
| 证据输出 | 仅图像 | 结构化数据 + Markdown + 色标 + 量化指标 |

#### 4.2.2.3 增强 / 对比效果展示

伪彩映射支持三种调色板：

- **绿色**（默认）：与 ICG 750–810 nm 激发下的视觉习惯一致；
- **琥珀**：在白光偏红的术野中提供高对比；
- **品红**：用于与绿色器械背景形成强对比。

色标图在阈值处标记白色刻度，并附黑色边框，便于医生在叠加图上回读强度等级。Fig 4-2 以公开人体 ICG 视频代理关键帧展示原始信号、候选叠加、风险与不确定性图层；该图用于说明软件复核流程，不提供颌骨骨髓炎病灶结论。

### 4.2.3 时间强度曲线

对于 MP4 视频流的关键帧序列，平台计算以下指标：

| 指标 | 计算方式 |
| --- | --- |
| 基线校正强度 | 首帧峰值强度减去背景强度 |
| 峰值校正强度 | 序列最大峰值强度减去背景强度 |
| 达峰时间 | 峰值帧相对首帧的时间差 |
| 最大上升斜率 | 归一化曲线相邻点差商最大值 |
| 归一化 AUC | 对基线-峰值归一化曲线积分 |
| 持续时间 | 末帧相对首帧的时间差 |

曲线点经过基线-峰值归一化到 [0, 1]，并显式标注为关键帧采样而非逐帧采集。稀疏关键帧时间强度指标仅作为工程灌注参考，跨病例解释需锁定采集协议与注射方案并由医生复核。

### 4.2.4 融合质量门控与失效保护

相位相关配准中内置三重门控，任一不满足即降级为不配准：

1. **响应门控**：配准响应低于安全阈值表明两通道相关性弱，配准结果不可信；
2. **平移幅度门控**：平移量上限按图像长边比例计算，防止异常大平移破坏图像；
3. **形状可用性门控**：图像最小边过小或两通道形状不一致时直接降级。

降级时返回配准未应用状态并记录原因字段，后续融合链在未配准图像上继续执行，报告中明确标注配准未应用。这种失效保护设计确保融合链在异常输入下仍可输出可用证据，同时通过原因字段提示医生复核时关注配准质量。

### 4.3.2 通道关系

白光与 ICG 成对分析仅属于 JPEG 路径：病例需同时录入白光 JPEG 与 ICG JPEG，两图尺寸允许不一致，由双线性重采样对齐到白光尺寸后再进入融合链。MP4 视频作为官方设备视频流示例，可触发播放、关键帧分析与连续帧串行推理，但不进入双通道融合路径。

设备叠加图（如赛题方 2026-07-17 确认的三路输出中的叠加图）仅用于显示、质控与证据核对，模型输入始终限定为原彩图与原始荧光图，叠加图不参与模型推理这一规则在质控契约中固定不变。

### 4.3.3 设备元数据接入

倍率、工作距离、相机标定、坐标变换与位姿记录通过离线清单或人工元数据接入，不依赖企业私有接口。清单字段示例：

| 字段 | 用途 |
| --- | --- |
| 总放大倍率 | 1.3–17× |
| 工作距离 | 200–630 mm |
| 视场直径 | 14–190 mm |
| 通道时间戳 | 用于三路同步校验 |
| 相机内参 | 用于 L1/L2 三维配准 |

任一字段缺失时，相关派生能力保持不可用状态，融合链与推理链仍可运行，仅物理量量化与三维配准功能受限。

### 4.3.4 三路输出质控

三路输出质控模块对原彩图、荧光图、设备叠加图执行三类校验：

| 校验类别 | 指标 | 默认阈值 | 失败状态 |
| --- | --- | --- | --- |
| 时间同步 | 通道间时间戳差 | ≤ 100 ms | 待复核 |
| 几何一致性 | 宽高比相对偏差 | ≤ 2% | 待复核，禁止像素比较 |
| 叠加图比较 | MAE / RMSE / SSIM / 边缘差异 | MAE ≤ 0.25，SSIM ≥ 0.35 | 待复核，输出差异热图 |

整体状态聚合为"通过/待复核/不可用"。当几何一致性失败时，叠加图像素比较被禁止，避免在尺寸不一致的图像上计算无意义的差异。差异热图采用伪彩着色并放大后裁剪到显示范围，用于医生肉眼核对其与软件叠加图的差异分布。

### 4.3.5 4K 分块推理与连续帧实时双路径

任务2与任务3采用独立延迟口径。项目团队提供的任务2详细文字将 `<100 ms` 明确用于白光/NIR2 配准与实时融合，因此任务2计时覆盖配准估计与变换、GPU 归一化、伪彩映射和 Alpha 混合。文件解码、背景校正、证据编码、磁盘写入、网络传输和任务3 AI 推理均分阶段记录。任务3只按术中可用性、异步刷新和医生复核工作流评价，没有毫秒级硬门。当前仓库保存的正式赛题 PDF 只写明“实时显示或辅助导航应用”，没有出现 100 ms 数值；终稿引用该数字时需同时归档项目团队提供的详细任务文字来源。

为兼顾 4K 全证据与实时性，平台在融合链下游提供两条推理路径，共享同一主线模型。

| 路径 | 输入 | 配置 | 性能 | 门控上限 |
| --- | --- | --- | --- | --- |
| 4K 分块全证据 | 3840×2160 JPEG | 分块尺寸 512，重叠 64，共 45 块 | 模型 P50/P95 = 415.7 / 724.4 ms；端到端 P50/P95 = 2181.5 / 5776.7 ms；GPU 峰值显存 723.6 MB | 端到端 P95 ≤ 15 s；模型 P95 ≤ 3 s；显存 ≤ 2048 MB |
| 连续帧实时 | 512×384 JPEG（前端长边 512，quality 0.85） | CUDA 混合精度、快速不确定性、低开销编码、病例预热、串行无积压 | 服务 E2E P50/P95 = 45.4 / 47.4 ms；模型 P50/P95 = 9.8 / 10.3 ms；峰值显存 109.5 MB | 每帧掩膜、风险掩膜、不确定性掩膜、JPEG 叠加图均有独立证据路径 |

4K 分块路径面向官方 4K JPEG 输入的全证据分割与证据包导出；连续帧实时路径面向 MP4 视频流的近实时同步分析。两条路径的输出契约一致，均产出骨面门控掩膜、荧光信号掩膜、边界风险掩膜、不确定性掩膜四类掩膜，其中骨面门控掩膜在无医生或 SAM 辅助标注前标注为"待复核"，不得伪造骨面真值。

### 4.3.6 4K 双通道成对融合验证

4K 合成工程验证实例的双通道成对融合结果作为本路径的工程验证基线。该实例使用程序生成的官方格式尺寸输入和工程临床上下文，用于验证文件接入、质量门、配准和安全回退链路：

| 字段 | 数值 |
| --- | --- |
| 白光 JPEG | 3840×2160，约 690 KB |
| ICG JPEG | 3840×2160，约 563 KB |
| 配准方法 | 自适应多尺度配准 |
| 配准响应 | 0.366592（远高于 0.08 安全门） |
| 平移量 | 接近亚像素级 |
| 配准应用 | 已应用 |

该结果验证了官方格式 4K 合成成对输入下的融合链可稳定运行：相位相关响应通过安全门，平移量接近亚像素级，配准链可在 4K 分辨率下直接运行而无需降采样。真实设备三通道同步、分光几何关系和配准误差需由后续实物文件验证。

新增 4K 配准与 GPU 融合内部工程门使用同一对可追溯 3840×2160 输入，向荧光图注入 `(+24, -16) px` 位移、平滑二次形变和移动遮挡。配准先缩放 RGB 工作图再提取灰度与多尺度边缘特征，使用分块相位测量驱动的 RANSAC 相似变换，并在完整 4K 荧光平面上执行单次 GPU affine+local-grid 重采样。局部残差场仅在残差 P95 超过激活门、拟合改善和幅度边界均通过时应用；上一帧局部场通过指数平滑交接，光学上下文变化时清空状态。120帧门中局部形变补偿覆盖率为 `100%`，局部残差 P95 从 `5.187 px` 降至 `1.361 px`，CUDA 零拷贝交接为 `120/120`，配准 P95 为 `59.022 ms`，GPU 归一化、伪彩与混合 P95 为 `21.891 ms`，逐帧计算合计 P50/P95 为 `71.464/82.026 ms`。全证据输出仍单独统计解码、背景校正、证据编码和写盘。

连续双通道工程门覆盖`1.3×到17×`和`200到630 mm`官方光学极值，复用上一帧全局变换与局部残差场执行指数平滑；低质量大跳变保持最近可信变换，倍率与工作距离变化触发时序状态重置。120帧中 JPEG 预览编码失败数为 `0`，显示就绪 P95 为 `102.219 ms`，计算超限率为 `0.833%`，最长重复超限为 `0`，单次孤立尖峰单独保留在证据中。任务2的`100 ms`口径继续只统计配准与融合，预览就绪采用独立的`200 ms`内部工程门。真实设备倍率、工作距离、帧同步与局部组织形变仍需独立标定和验证。
