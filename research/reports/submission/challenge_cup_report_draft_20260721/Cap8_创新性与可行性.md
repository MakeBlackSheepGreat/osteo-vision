# 第 8 章 创新性与可行性

---

## 8.1 创新点

平台软件的创新点按技术层、工程层、临床层三轴组织。每一项创新点均给出可核验承载：输入契约、配置文件、模型权重、清单或报告路径，避免停留在方案描述。

### 8.1.1 技术层

#### （1）候选造影剂组合：ICG 基线 + 多信号互补 + 模块化探针猜想

针对 ICG 仅反映血流灌注、血管通透性与组织活性差异、对颌骨骨髓炎无特异性结合这一文献共识（详见第 3 章），平台软件在不进行实物合成与湿实验验证的前提下，提出可工程核验的候选造影剂组合路线：

- **ICG 基线**：与赛题方显微镜激发 750–810 nm / 发射约 830 nm 光学窗口匹配，作为血流灌注与组织活性参考信号通道；EAES 2023 共识将组织灌注评估最低剂量定为 2.5–10 mg，推荐 0.25–0.5 mg/kg。
- **第二信号候选 A — Evans blue**：基于血管通透性差异示踪机理，作为 ICG 之外的可文献复核互补信号。
- **第二信号候选 B — 四环素类自体荧光猜想**：基于骨结合特性，激发 405–460 nm、发射 500–560 nm，作为骨面/死骨识别的文献研究方向；当前定位为猜想，未做实物合成。
- **新型骨亲和探针模块化设计**：按"骨亲和端 / 感染识别端 / 近红外发光端 / 连接臂"四模块拆分，按 A0–A4 分级实验矩阵组织后续验证路径。
- **工程替代证据**：在 4K 验证病例（67 岁、男、2 型糖尿病、高血压、CRP 32 mg/L）上以白光 + ICG 双通道完成配准、归一化、伪彩、ROI 时序曲线与灌注/活性比值的端到端可核验输出，配准响应 0.366592 远高于 0.08 安全门。

#### （2）多模态融合算法：十步融合链 + 三路质控

白光与荧光双通道融合模块实现十步融合链，全部步骤在源码中可逐行复核：

1. 双通道输入校验与尺寸对齐；
2. 相位相关亚像素配准；
3. 百分位归一化（避免极值压缩）；
4. 伪彩查表生成；
5. Alpha 混合（按质量门动态权重）；
6. CLAHE 局部对比度增强；
7. ROI 提取与时序曲线记录；
8. 质量门标记（配准响应、通道一致性）；
9. 输出契约写入（融合结果 + 三路质控字段）；
10. 失效保护回退（任一门控失败 → 回退模式）。

三路输出质控模块承接赛题方 2026-07-17 确认可提供原彩 / 荧光 / 叠加三路输出的能力，对三路输出执行一致性校验，质量门字段写入证据清单。融合算法在 4K 验证病例上验证双通道成对分析路径，配准响应 0.366592，远高于 0.08 安全门；融合结果、ROI 时序曲线与质量门字段全部进入可核验证据包。

#### （3）多模态 AI 判读模型：残差注意力 U-Net + 骨活性多任务 v2 + 患者条件分割

平台软件主线模型与多任务候选均通过统一适配器接口接入，由统一推理服务调度。三组模型在源码、配置、模型权重、清单与报告中均可核验：

| 模型 | 关键设计 | 工程状态 |
|---|---|---|
| 残差注意力 U-Net（主线） | 残差注意力 U-Net；关键帧主线分割；参数量约 40 万；运行阈值 0.4 | 主线已接入比赛配置；4K 运行门控与连续帧实时运行门控均通过 |
| 骨活性多任务 v2 候选 | 双编码器 + 融合 + U-Net 多头解码器；4 个输出头（低活性 / 过渡 / 高活性 / 忽略区）+ 连续评分头 | 代理域训练完成；工程实用门未通过，未替换主线 |
| 患者条件分割候选 | 13 项临床特征向量（年龄、性别、基础病、用药、血液指标等） | 受限患者条件分割；影像基础 + 患者条件 + 差异图 + 安全回退；无伤害 / 亚组 / 物理边界三门失败；强制空间效应不应用 |

输出契约统一为四类掩膜：骨面门控掩膜、荧光信号掩膜、边界风险掩膜、不确定性掩膜；其中骨面门控掩膜在医生 ROI 或提示辅助复核生成前仅记录为待复核/不可用，不作为骨面真值。骨活性多任务 v2 在掩膜之上叠加连续骨活性评分（0–1 灰度），形成"候选区 + 边界风险 + 不确定性 + 连续谱"的组合输出。

### 8.1.2 工程层

#### （1）设备解耦与清单接入

平台软件保持设备解耦，只负责官方 JPEG/MP4、三路图像文件及可选标准化元数据进入软件后的分析、医生复核、证据与安全降级。倍率、工作距离、相机标定、坐标变换与位姿记录通过离线清单或人工元数据接入，不依赖企业私有接口。推理运行配置在每个模型项设置设备策略为自动，无 GPU 时仍可工作，仅推理延迟上升。赛题方设备、医院自有设备分别按设备来源、准确型号、固件版本与采集配置独立登记，两类设备的资料、样本、接口与验证结果互不推定。

#### （2）批次准入与样本状态机

输入准入服务与医院准入服务联合实现批次准入流程：

- 文件签名、可解码性、SHA256、重复项、通道关系、同步配对校验；
- 通过 / 隔离 二态准入：只有通过准入的文件可登记为病例输入，被隔离的文件仅保留原因码；
- 新准入样本默认标记为"待复核""无标签""训练准入否"；
- 机构授权、脱敏确认、病例映射保管、用途范围、来源、接收人与时间全部写入清单；
- 医院或医生交接的真实 JPEG/MP4 在写入平台病例、进入分析或形成训练清单前必须完成上述准入。

#### （3）医生复核闭环：双签晋级 + 哈希链审计 + 复核权重

医生复核闭环由复核服务、晋级审批服务与人工标注服务联合承载：

- **身份校验**：晋级审批需可信身份源的角色为医生或项目复核者，强制身份校验通过后才能进入双签流程。
- **追加式哈希链**：按序号、审批 ID、随机数、目标指纹与上一记录哈希写入；随机数唯一约束保证审批记录不可重放。
- **双签晋级**：晋级审批需两名独立具备医生或项目复核者角色的可信身份依次签名方可生效。
- **复核权重**：通过 4.0、修改 4.0、驳回 0.5、待复核 1.0；通过或修改的样本进入高权重训练清单，驳回样本默认作为负例或错误分析数据，待复核保持待复核权重。
- **人工标注页面**：支持从病例 JPEG、MP4 关键帧和模型候选区进入，提供画笔、橡皮擦、多边形、撤销/重做、缩放、标签选择、草稿保存、提交复核与版本历史；后端持久化原图尺寸坐标、像素掩膜、标注类别、医生身份、机构、时间、来源输入、病例、版本、复核状态与训练准入状态。

#### （4）证据包：结构化数据 + 量化表格 + Markdown + DICOM SC + ZIP

导出打包服务联合生成五类格式证据包：

- **结构化数据**：结构化病例元数据、四类掩膜路径、量化指标、复核状态、运行配置、SHA256；
- **量化表格**：量化指标按 ROI / 关键帧 / 时间序列输出，便于二次统计；
- **Markdown**：平台报告生成模块生成可读报告，含平台安全边界与医生复核免责声明；
- **DICOM Secondary Capture**：按 SC 形式构造证据摘要对象，写入病例号与证据摘要描述，承载证据截图与量化结果，定位为证据包扩展，非诊断性 DICOM 输出；
- **ZIP**：上述四类产物按证据包 SHA256 索引打包，写入证据清单。

### 8.1.3 临床层

#### （1）术中实时性：双路径运行门控

平台严格区分"有效帧率"与"采样率"，在两条路径上分别测量并落地门控：

| 路径 | 模型 P95 (ms) | 服务 E2E P95 (ms) | 峰值显存 (MB) | 门控 |
|---|---:|---:|---:|---|
| 4K 分块全证据 | 724.432 | 5776.683（约 5.78 s） | 723.579 | 通过（≤15 s / ≤3 s / ≤2048 MB） |
| 连续帧实时 | 36.377 | 176.457 | 380.134 | 通过 |

4K 分块路径覆盖官方 4K JPEG/MP4 输入下的全证据分析；连续帧实时路径覆盖术中连续帧实时叠加。两条路径共享同一模型权重与同一四类掩膜输出契约，仅分块/平铺与精度配置不同。

#### （2）边界风险提示：边界风险掩膜 + 不确定性掩膜

四类掩膜输出契约中，边界风险掩膜承载边界风险与过渡区决策提示，不确定性掩膜承载低置信或质量受限区。两个掩膜由模型概率图、质量门字段与骨活性多任务候选区联合派生，在界面中以独立图层呈现，明确标注"术中参考信号、非自动确诊"。医生可在人工标注页与复核工作台中对两个掩膜进行修改、驳回或通过，复核结果回灌至训练清单。

#### （3）医生交互判读流程改造

平台软件在不改变医生最终判读权的前提下，对传统术中判读流程进行工程化改造，对照如下：

| 阶段 | 传统流程 | 改进后流程 |
|---|---|---|
| 1 | 术前影像（X 线 / CBCT / MRI） | 术前影像 + 病例准入（批次准入、SHA256、通道关系） |
| 2 | 经验性术中判读（肉眼、触诊、术中 X 线） | 4K 术中视频流进入四宫格"视频流输入"视口 |
| 3 | 肉眼/触诊定边界 | 白光/ICG 配准融合 + 十步融合链 + 三路质控 |
| 4 | 清创 | AI 候选区 + 边界风险掩膜/不确定性掩膜风险提示 + 骨活性连续谱 |
| 5 | 序列治疗与随访 | 医生复核定边界（双签晋级 + 哈希链审计）→ 证据包回灌 |

改进后的流程在保留医生最终判读权的前提下，引入实时信号、量化指标、可追溯记录与三维延伸能力；所有改进点均以工程可核验为限，不构成临床诊断性能证据。

#### （2）4K 与连续帧实时双路径运行门控

4K 运行门控通过：端到端 P95 5.78 s ≤ 15 s、模型 P95 724 ms ≤ 3 s、显存 724 MB ≤ 2048 MB。连续帧实时运行门控通过：服务 E2E P95 176 ms、模型 P95 36 ms。两条路径共享同一模型权重，保证分割质量在双路径下一致。

#### （3）融合算法可核验

4K 双通道成对分析在验证病例上完成：配准响应 0.366592，远高于 0.08 安全门；ROI 时序曲线、灌注/活性比值、伪彩叠加、融合图全部进入证据包。

#### （4）三维 L1/L2 工程验证

公开数字下颌仿体 L1 FRE 2.93e-14 mm、TRE 2.34e-14 mm、重投影 6.23e-14 px；6/6 帧 L2 软件门通过。L1 静态仿体配准与 L2 离线动态 AR 完成工程验证，所有 L1/L2 工程结果当前保持导航就绪标记为否、导航声称允许标记为否。

#### （5）与现有显微成像系统的输入边界兼容

赛题方手术显微镜 4K USB3.0 输出，分辨率 3840×2160，图片格式 JPEG，视频格式 MP4；官方技术文档确认上述接口。平台软件以 4K JPEG/MP4 为一级可见输入方式，三路图像（原彩 / 荧光 / 叠加）通过清单接入，倍率、工作距离、相机标定、坐标变换与位姿记录通过离线清单或人工元数据接入。上述边界已在源码、配置、批次准入流程与证据包中固化。

> 边界说明：上述所有指标属于公开、代理或伪标注非目标域，仅证明工程可行性与架构比较，不构成真实术中 ICG 颌骨骨髓炎临床性能证据。

### 8.2.3 临床可行性

#### （1）保留医生复核边界、不替代医生判断

平台软件在所有输出层均保留医生复核免责声明。AI 候选区、风险提示、不确定性可视化、骨活性连续谱与三维工作台 L1/L2 工程验证均为医生术中参考信号与复核辅助，最终判读权与最终判读依据始终保留在医生侧。骨面门控掩膜在医生 ROI 或提示辅助复核生成前仅记录为待复核/不可用；通过或修改的复核样本进入高权重训练清单，仍不等同于真实目标域临床标注。

#### （2）与医院现有流程可对接

当前医生合作单位为绵阳市第三人民医院头颈部颌面甲状腺科，现场设备为医院自有设备，与成都赛题方的设备属于两套独立设备；医院设备确认可导出 JPG 与 AVI，并提供黑白荧光和伪彩显示模式，原彩或独立白光模式的导出能力仍待医院设备侧确认。平台为医院 AVI 建立受控转码流程，保留原始 AVI、SHA256、编解码参数、转码日志与原始文件到 MP4 的对应关系。医院设备的格式、显示模式、参数与接口不推定为赛题方设备能力；两类设备的资料、样本、接口与验证结果分别记录设备来源、准确型号、固件版本与采集配置。近期医院可采集的 ICG 病例以软组织手术为主，颌骨相关病例时间不确定，软组织 ICG 数据作为设备、信号与时序工程验证域，颌骨骨髓炎或颌骨相关 ICG 作为目标域，两类数据分层保存、分组评估。

### 8.2.4 可推广性边界

平台软件当前的可推广性边界明确如下：

- **当前证据以公开/代理数据为主，目标域数据待补**：分层数据注册表共 504 条记录，目标域记录 0，训练准入记录 0；所有训练指标均属于非目标域工程证据。
- **真实目标域数据缺失**：真实术中 ICG 颌骨骨髓炎 MP4/JPEG/CBCT 缺失；医生关键帧/ROI 标注暂缺；软组织 ICG 数据不包装成目标域训练数据或颌骨临床性能证据。
- **患者条件分割三门失败**：无伤害门、亚组门、物理边界门均失败；运行时强制空间效应不应用、差异为零，概率回退为影像基础，差异掩膜全零；目标域晋级不允许、运行时替换不允许、临床声称不允许。
- **骨活性 v2 两预设失败**：接受覆盖率 0.056417（预设 ≥0.10 失败）、选择性错误率 0.301527（预设 ≤0.15 失败）；工程实用门未通过，未替换主线。
- **三维导航边界**：所有 L1/L2 工程结果当前保持导航就绪标记为否、导航声称允许标记为否；前端三维工作台以"未配准参考"承载显示。
- **多中心、概率校准、亚组审计、注册合规**：纳入后续规划（详见第 9 章），当前不声称已具备多中心临床验证能力。
