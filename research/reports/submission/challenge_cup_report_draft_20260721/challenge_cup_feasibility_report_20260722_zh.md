## 1.1 颌骨骨髓炎概述

### 1.1.1 流行病学与分型

颌骨骨髓炎（jaw osteomyelitis）是累及颌骨骨皮质与骨髓质的感染性或炎症性疾病，多由牙源性感染扩散、牙外伤、拔牙并发症或颌面部创伤引起，少部分继发于血源性感染、放疗或抗骨吸收药物使用。下颌骨因骨质致密、血供相对单一，发生率高于上颌骨。

依据病因与病程，临床通常将颌骨骨髓炎分为以下类型：

| 分型 | 主要诱因 | 典型病程 |
| --- | --- | --- |
| 急性颌骨骨髓炎 | 牙源性感染、急性创伤 | 起病急，疼痛、发热、局部肿胀显著 |
| 慢性颌骨骨髓炎 | 急性期未彻底控制或反复发作 | 病程迁延，可见瘘管、死骨、间歇性排脓 |
| 继发性颌骨骨髓炎 | 放射治疗后、外伤后、糖尿病等基础病 | 病程复杂，血供与全身状况差 |
| 药物相关性颌骨骨坏死（MRONJ） | 双膦酸盐、地诺单抗等抗骨吸收药物 | 暴露骨面迁延不愈，难愈合并感染 |
| 放射性骨坏死（ORNJ） | 头颈部放疗后骨坏死 | 放疗区域骨坏死伴软组织损伤 |

不同分型在病理机制、治疗策略与术中判读难点上存在差异，共同表现为病灶边界难以精确判定、活性骨与死骨鉴别困难、术后复发风险较高等问题。

### 1.1.2 发病机制

颌骨骨髓炎的发病机制涉及多种因素的叠加作用：

- **感染源**：牙源性感染是急性颌骨骨髓炎最主要的来源，致病菌以葡萄球菌、链球菌和厌氧菌为主，部分病例合并多种菌群感染；
- **血供破坏**：颌骨血供单一，下颌骨主要依靠下牙槽动脉供血，感染、外伤或手术破坏血供后，骨内压力升高、静脉回流受阻，进一步加重骨坏死；
- **药物相关骨坏死**：双膦酸盐、地诺单抗等抗骨吸收药物抑制骨重塑，长期使用可导致局部骨代谢失衡，合并创面或拔牙时诱发颌骨坏死；
- **外伤与放射性因素**：颌面部骨折、放射治疗后骨细胞损伤、血管纤维化等均可破坏骨组织活性，形成继发性骨坏死病灶；
- **免疫与基础病**：糖尿病、免疫抑制、长期糖皮质激素使用等因素可显著降低局部抗感染与愈合能力。

### 1.1.3 临床表现

颌骨骨髓炎的典型临床表现包括：

- 持续性颌面部疼痛，可放射至耳颞区或下牙槽神经分布区；
- 局部肿胀、皮温升高、张口受限；
- 牙齿松动、咬合紊乱、口内或面部瘘管形成，伴有脓性分泌物；
- 受累神经区感觉异常，如下唇或颏部麻木；
- 病程较长者出现面部畸形、病理性骨折、口内外瘘管贯通；
- 影像检查可见骨密度不均、死骨形成、骨膜反应与骨质破坏。

### 1.1.5 现有治疗路径

当前颌骨骨髓炎的治疗遵循"全身支持 + 局部清创 + 缺损修复"的序列治疗原则：

1. **全身抗感染**：根据细菌培养与药敏结果使用抗生素，急性期以广谱抗生素为主，慢性期需结合厌氧菌覆盖；
2. **病灶清创**：彻底清除死骨与炎性肉芽组织，直至暴露出血的健康骨面；清创范围依赖术者经验判断，过度清创可造成骨缺损扩大，清创不足则易复发；
3. **血供重建与软组织覆盖**：对血供破坏严重或大面积骨缺损者，采用局部或游离瓣修复，改善局部血供与软组织覆盖；
4. **序列修复**：包括牙列修复、咬合重建、颌骨重建与种植等后期处理；
5. **基础病管理**：糖尿病血糖控制、抗骨吸收药物停用或调整、营养支持等。

### 1.1.6 核心临床痛点

综合上述流程，颌骨骨髓炎手术存在四类长期未解的临床痛点：

1. **病灶边界不清**：肉眼与影像学难以在术中精确判定死骨与活性骨的过渡边界；
2. **过度清创或清创不足**：过度清创扩大骨缺损、损害颌骨连续性，清创不足则残留感染灶导致复发；
3. **复发率较高**：慢性与继发性颌骨骨髓炎术后复发率仍处于较高水平；
4. **术中实时判读缺位**：传统影像学为术前信息，难以实时反馈术野清创状态与组织活性。

## 1.2 当前疾病诊疗方式与不足

### 1.2.1 传统术前评估

传统术前评估以影像学与活检为主：

- **X 线全景片与 CT**：可整体观察骨质破坏范围、死骨形态与骨膜反应，但早期骨髓炎信号弱，分辨率有限；
- **CBCT**：在牙科与颌面外科应用广泛，可提供三维骨质信息，但功能信息有限；
- **MRI**：软组织对比好，可评估炎性水肿与脓肿范围，但对骨皮质细节描述较弱，设备体积与术中可用性受限；
- **活检与细菌培养**：提供病理与微生物学诊断，属于术前或术中切片检查，无法在术野中实时反馈；
- **血液检查**：炎症指标与基础病评估为辅助信息，缺乏局部病灶定位能力。

### 1.2.2 传统术中判读

术中判读主要依赖：

- 术者**肉眼观察**骨面颜色、出血情况、骨质硬度；
- **触诊**判断骨面松软度、死骨松动度；
- **术中 X 线或 CBCT** 复核（条件具备时），需要中断手术、更换体位或推进设备；
- **术中冰冻切片**（条件具备时），耗时较长且取样点有限。

### 1.2.3 存在的主要问题

| 序号 | 问题 | 表现 |
| --- | --- | --- |
| 1 | 影像与术中实时性脱节 | 术前影像难以反映术野清创过程中的实时组织状态 |
| 2 | 死骨与活性骨边界依赖经验 | 肉眼与触诊存在主观差异，过渡区判读一致性有限 |
| 3 | 缺乏定量与可复核指标 | 术中判读结果难以量化、难以追溯，病例证据缺失 |
| 4 | 难以支持术中即时决策 | 缺乏可在术中即时反馈的辅助信号与候选区提示 |

上述不足共同导致颌骨骨髓炎手术在术中边界判定、术中决策与术后证据三个环节缺乏可量化的辅助工具。

## 1.3 国内外技术研究现状

### 1.3.1 荧光造影与术中导航

#### 1.3.1.1 ICG 在外科的临床应用与文献证据

吲哚菁绿（ICG）为水溶性三碳菁染料，1956 年起用于临床。其光学特性为最大吸收约 800 nm，发射峰约 835 nm；在近红外光（约 750–810 nm）激发下发射约 830 nm 荧光。ICG 静脉注射后迅速与血浆白蛋白结合，主要存在于血管内，半衰期 3–5 分钟，经肝脏与胆汁快速代谢。

ICG 荧光成像在外科领域已有较广应用，主要包括：血管通畅性与血流方向评估、肿瘤边界识别（如脑胶质瘤血脑屏障破坏区域）、血流灌注动态评估、组织活性判断、淋巴示踪等。赛题方荧光手术显微镜在 ICG 光学窗口上与上述使用场景一致，激发 750–810 nm、发射约 830 nm。

下表汇总了与本项目最相关的 ICG 文献证据：

| 文献 | 场景 | 关键结论 |
| --- | --- | --- |
| EAES 2023 共识 | ICG 荧光成像外科应用 | ICG 荧光成像"有前景、安全、有效"，但"不应作为单一诊断工具" |
| Dhiman 等 2022 系统综述 | 23 项 NIR-ICG 研究、452 例患者 | 系统综述支持 ICG 在术中辅助判读中的潜力，但样本与方法异质性较大 |
| Yoon 等 2019 | ICG 辅助近红外牙科成像 | 首次体内验证 ICG 辅助近红外牙科成像可行性 |
| 显微镜 ICG 视频 AI 语义分割（2022） | 显微镜下 ICG 视频语义分割 | 最接近赛题工程形态的研究 |
| Naraghi 等 2018 | 深部骨感染 | ICG 可显示深部骨感染区域 |
| Goloborodko 等 2024 | 115 例 NSTI 患者 | 存活感染组织均显荧光、坏死组织均无荧光，未在颌骨骨髓炎大样本验证 |
| Kang 等 2019 | ICG 药代动力学 | 提出骨特异性 ICG 药代动力学模型 |

#### 1.3.1.2 ICG 现有不足

赛题官方文档明确指出："ICG 在颌骨骨髓炎手术中容易受炎症、充血、水肿和操作因素影响，不能准确区分病灶组织与潜在活性骨组织"。结合文献证据，ICG 在颌骨骨髓炎场景下的局限可归纳为：

- **机理局限**：反映血流灌注、血管通透性与组织活性差异，缺乏颌骨骨髓炎特异性结合；
- **边界区分有限**：坏死骨与活性骨的对比主要依赖灌注差，炎症充血区亦呈高信号；
- **早期信号弱**：给药后早期局部信号弱，受背景与噪声影响；
- **单一诊断不足**：临床共识不推荐作为单一诊断工具；
- **颌骨证据规模有限**：现有颌骨近域证据以小样本与近域场景为主。

#### 1.3.1.3 替代与增强方向

为弥补 ICG 在骨活性判读上的不足，文献中已提出多种替代或增强方向：

- **四环素类骨结合荧光**：四环素类抗生素与钙结合，在活跃矿化与骨重塑区域沉积，活骨呈明亮绿色或黄绿色荧光，坏死骨呈低荧光或无荧光。激发波段 405–460 nm 紫蓝光，发射峰值约 529 nm，集中在 500–560 nm。相关文献包括 Pautke 2010、Ristow 2017 与 2020，以及 MRONJ 荧光引导手术荟萃分析（285 名患者、314 个病灶）；
- **自体荧光**：骨组织在紫外/紫蓝光激发下产生的内源性荧光，可作为无造影剂的活性参考信号；
- **Evans blue 通透性示踪**：与血清白蛋白结合，反映血管通透性与蛋白渗漏，可作为炎性软组织通透性参考，原始产品在临床已停产。

上述方向的光谱、机理与临床可得性存在差异，难以单独替代 ICG，因此本项目采用"ICG 灌注基线 + 第二信号补充 + 模块化新型探针设计"的组合思路，详见第 3 章。

### 1.3.2 医学图像智能分析

#### 1.3.2.1 多模态融合

医学图像分析已从单一模态向多模态融合演进，结构信息（CT、CBCT、白光图像）与功能信息（荧光、灌注、自体荧光）的联合分析成为术中辅助判读的重要方向。颌骨骨髓炎场景下，白光通道提供解剖结构、ICG 通道提供灌注与血管通透性信息、四环素/自体荧光提供骨活性参考，三者融合可形成多层级信号组合。

#### 1.3.2.2 模型与任务演进

| 维度 | 演进路径 |
| --- | --- |
| 网络结构 | CNN → Transformer → Mamba 等 SSM 架构；医学图像分割领域出现 nnU-Net、MedNeXt、U-Mamba、MedSAM、SAM2 等代表工作 |
| 任务粒度 | 分类 → 检测 → 分割 → 不确定性提示 → 多任务联合 |
| 输入形态 | 单帧 2D → 帧序列 → 视频 → 多模态配准输入 |
| 输出契约 | 单一分类 → 多掩膜分割 → 概率图 → 候选区 + 风险图 + 不确定性图 |

#### 1.3.2.3 当前空白与本项目切入点

结合上述现状，颌骨骨髓炎术中荧光辅助判读领域存在三方面明显空白：

1. **术中实时性不足**：现有研究多停留在离线图片或离线视频分析，术中实时反馈链路较弱；
2. **目标域数据稀缺**：真实术中颌骨骨髓炎 ICG 视频与医生标注样本极度缺乏，公开数据集多为近域或代理数据；
3. **医生交互闭环弱**：现有 AI 模型输出缺乏医生复核、修改与回灌训练的可控链路。

本项目的切入点在于：构造"造影剂设计 + 多模态融合 + AI 判读 + 医生复核"的完整方案，在赛题官方 4K JPEG/MP4 输入边界下实现端到端可运行闭环，并通过医生复核回灌与证据包导出支撑后续临床验证。

## 2.1 系统总体架构

### 2.1.1 总体设计原则

本系统总体设计遵循以下原则：

- **以患者安全为第一**：所有创新点先完成风险识别、医生复核边界、失效保护与不可声称范围定义，再进入比赛展示与后续验证；
- **设备解耦**：平台软件与硬件设备解耦，仅处理官方 JPEG/MP4、三路图像文件及可选标准化元数据进入软件后的分析、复核、证据与安全降级（详见 2.1.7）；
- **配置与契约驱动**：模型、数据集、阈值、坐标约定、复核流程与输出契约统一通过配置文件与清单进入工程；
- **可复核与可追溯**：病例准入、模型推理、医生复核与回灌训练全过程保留证据链与版本历史。

### 2.1.3 平台软件层：三层结构

平台软件在双通道数据进入系统后承担后三层任务，各层职责与关键能力如下：

| 层次 | 主要职责 |
| --- | --- |
| 荧光分析层 | 白光/ICG 双通道配准、伪彩、融合、归一化、质控、ROI 定量、时间序列分析 |
| AI 与医生交互判读层 | 候选区、边界风险、不确定性提示、骨活性分层、医生复核与人工标注 |
| 结果输出层 | 关键截图、结构化数据、量化表格、Markdown 报告、病例证据包与 DICOM 扩展 |

#### 2.1.3.1 荧光分析层关键能力

白光与荧光双通道融合模块实现白光与荧光双通道的十步融合链，包括尺寸对齐、背景扣除、相位相关平移配准、百分位归一化、伪彩映射、白光叠加、色标生成、ROI 定量与报告输出，并对输出图像、掩膜、热图与色标建立唯一证据路径。三路输出质控模块对赛题方原彩图、荧光图与叠加图三路输出执行一致性、通道关系与时间戳质控。

#### 2.1.3.2 AI 与医生交互判读层关键能力

AI 推理由统一推理服务调度，模型通过适配器接口注册进入。术中视频分割按"视频信号分割"任务定位：暴露骨区域、荧光/灌注信号、时间稳定性、边界风险与不确定性提示的组合，不直接包装为疾病终判掩膜。该层输出四类掩膜与一个连续评分：

| 输出契约 | 含义 | 标注来源 |
| --- | --- | --- |
| 骨面门控掩膜 | 暴露骨面或疑似骨面 | 医生或提示辅助复核（无医生/SAM 辅助前标注"待复核"） |
| 荧光信号掩膜 | 高荧光/灌注信号候选 | 可训练或启发式代理 |
| 边界风险掩膜 | 边界风险提示 | 可训练或启发式代理 |
| 不确定性掩膜 | 低置信或质量受限区域 | 质量或复核信号 |
| 骨活性连续评分 | 0–1 信号参考值 | 复核候选 |

医生复核回灌通过人工标注与复核服务实现：人工标注支持画笔、橡皮擦、多边形、撤销/重做、缩放、标签选择、草稿保存、提交复核与版本历史；医生复核状态分为"通过"、"修改"、"驳回"与"待复核"四类，对应不同训练准入权重。后端持久化字段覆盖原图尺寸坐标、像素掩膜、标注类别、医生身份、机构、时间、来源输入、版本、复核状态与训练准入状态。

#### 2.1.3.3 结果输出层关键能力

平台报告模块聚合病例记录、分析运行、临床上下文评估、患者条件证据、骨活性证据、视频信号分割、三路质控、三维证据、ROI、复核事件与产物列表，输出结构化报告并嵌入平台安全免责声明与 ICG 信号局限性说明。其余模块分工为：量化表格模块输出 ROI 量化表、Markdown 报告模块输出可读报告、DICOM Secondary Capture 模块输出证据截图扩展、证据包整合模块打包为 ZIP 病例证据包（附带模型、配置、阈值、SHA256、身份与复核状态）。

### 2.1.4 用户与医生侧

平台面向主刀医生（确认边界、调整阈值、接受或修改 AI 建议、双签晋级）、术中助手（导入图像或帧序列、选择关键帧、补充术中备注）、科研人员（回看病例、导出证据包、批量统计与模型评估）与平台管理员（配置模型版本、报告模板、导出格式与权限）四类角色提供工作流。

### 2.1.5 数据闭环与端到端演示

平台采用"病例准入 → 模型推理 → 医生复核 → 回灌训练"四阶段闭环：

1. **病例准入**：医院或医生交接的真实 JPEG/MP4 在写入病例前执行批次准入，记录机构授权、脱敏、用途范围与接收信息，校验文件签名、可解码性、SHA256、重复项、通道关系与同步配对；只有通过准入的文件登记为病例输入，被隔离的文件仅保留原因码；
2. **模型推理**：4K JPEG/MP4 进入平台后执行配准、伪彩、融合、归一化、质控、ROI 定量与关键帧/连续帧分割推理，输出四类掩膜、骨活性连续评分与候选区；
3. **医生复核**：医生对 AI 候选区进行复核、修改或驳回，状态由"通过/修改/驳回/待复核"区分；只有可信医生身份提交且完成独立复核的标注进入高权重训练评估；
4. **回灌训练**：通过或修改后的样本作为高权重训练数据，驳回样本作为负例或错误分析数据，训练报告须说明权重仍不等同于真实目标域临床标注。

# 第 3 章 荧光造影剂设计

## 3.1 设计目标

### 3.1.1 颌骨骨髓炎术中场景特点

颌骨骨髓炎术中视野同时存在出血、活动性灌注、炎性充血、坏死骨与残存活骨等多种信号源，且各类信号在白光下的视觉差异有限。赛题方荧光手术显微镜支持 4K 超高清影像摄录（3840×2160），并通过电动/手动 6.2:1 连续变倍实现 1.3×–17× 总放大倍，工作距离 200–630 mm，视场直径 14–190 mm，可变倾角主刀镜 0°–200°。术者在不同放大倍率与工作距离下切换时，成像视场、景深、单位像素对应的物理尺寸发生显著变化，对造影剂的信号强度、对比度稳定性与边界可分性提出了较高要求。

术中对造影剂的核心诉求可归纳为：

- **快速**：给药后能在数分钟内进入成像窗口，匹配清创决策节奏；
- **特异**：在炎性充血、出血、创面渗出的背景下仍能反映骨活性或死骨差异；
- **低毒**：单次或有限次给药不引入额外感染、耐药、肝肾或皮肤风险；
- **可复核**：信号在医生复核窗口内可重复观测，便于多角度、多倍率确认。

赛题官方文档已确认显微镜 ICG 光学窗口为激发 750–810 nm、发射约 830 nm；该窗口既约束了 ICG 的工作条件，也为新型探针的近红外发光端设计提供了设备匹配目标。

### 3.1.2 目标分解

结合上述场景，本章将造影剂设计目标分解为以下三条：

1. **提升骨面、死骨与活性区的信号对比**：在 ICG 灌注信号之外补充能区分骨活性边界的第二信号，使死骨、低活性骨、高活性骨、炎性软组织在荧光图像中形成可分级的强度差。
2. **与 ICG 联合使用时无通道串扰**：新型探针的激发/发射光谱应与 ICG 750–830 nm 窗口在光谱、时间或空间上可分离，避免双通道叠加时出现相互泄漏。
3. **与显微荧光成像系统激发/发射匹配**：候选探针的发光波段应能在赛题方显微镜现有或扩展光源/滤光片配置下采集，避免依赖完全重建光路。

## 3.2 设计思路

### 3.2.1 ICG 既有方案的不足

ICG 为水溶性三碳菁染料，1956 年起用于临床，与血浆白蛋白结合后经肝脏快速吸收，半衰期 3–5 分钟，完全经胆汁排出。其最大吸收约 800 nm，发射峰约 835 nm。EAES 2023 共识将组织灌注评估最低剂量定为 2.5–10 mg，推荐 0.25–0.5 mg/kg，最高 2 mg/kg；静脉注射后约 10 分钟开始成像，窗口 3–5 分钟。

在颌骨骨髓炎场景下，ICG 的主要局限如下表所示：

| 局面 | 表现 | 文献依据 |
| --- | --- | --- |
| 机理局限 | 反映血流灌注、血管通透性与组织活性差异，对颌骨骨髓炎无特异性结合 | 赛题原文明确"ICG 在颌骨骨髓炎手术中容易受炎症、充血、水肿和操作因素影响，不能准确区分病灶组织与潜在活性骨组织" |
| 边界区分有限 | 坏死骨与活性骨在 ICG 下的对比主要依赖灌注差，炎症充血区亦呈高信号 | Naraghi 等 2018 显示 ICG 可显示深部骨感染区域；Goloborodko 等 2024 在 115 例 NSTI 患者中发现存活感染组织均显荧光、坏死组织均无荧光，但该结论未在颌骨骨髓炎大样本中验证 |
| 单一诊断不足 | 临床共识不推荐作为单一诊断工具 | EAES 2023 共识：ICG 荧光成像"有前景、安全、有效"，但"不应作为单一诊断工具" |
| 证据规模有限 | 现有颌骨近域证据以小样本与近域场景为主 | Dhiman 等 2022 系统综述覆盖 23 项 NIR-ICG 研究、452 例患者；Yoon 等 2019 首次体内验证 ICG 辅助近红外牙科成像可行性；2022 年显微镜 ICG 视频 AI 语义分割为最接近赛题工程形态的研究 |
| 药代模型尚不专一 | 骨特异性药代动力学仍属建模阶段 | Kang 等 2019 提出骨特异性 ICG 药代动力学模型 |

基于上述不足，本项目在保留 ICG 作为灌注层基线的同时，提出通过 Evans blue 通透性示踪与四环素类骨结合荧光两条文献路线补充第二信号，并以模块化设计探索面向颌骨死骨选择性的新型骨亲和近红外探针。

### 3.2.2 候选 A — Evans blue：血管通透性差异

**机理定位**：Evans blue 强结合血清白蛋白，临床上曾用于血浆容量测定、血管通透性评估、蛋白渗漏与淋巴示踪。其吸收峰约 620 nm，与白蛋白结合后发射约 680 nm，可作为炎性软组织通透性升高的参考信号。

**项目定位**：原始 Evans blue 不进入患者应用主线。该候选仅保留作为白蛋白结合/通透性探针的设计启发，以及在非骨前临床数据中的机理对照。历史 FDA 注射产品已停产，当前在售标签检索未发现可用产品，相关衍生物文献证据见于近年期刊发表。

**与颌骨死骨任务的差距**：

- 缺少颌骨与死骨选择性依据，炎症、充血、创面与血管通透性升高均可能产生白蛋白渗漏信号；
- 约 680 nm 发射处于可见光/近红外边界，表面成像时组织穿透与背景控制通常弱于 ICG 750–830 nm 近红外窗口；
- 历史产品停产与监管状态使其难以直接作为术中人体造影剂使用。

Evans blue 路线在本章的作用集中于：为新型骨亲和探针的"感染识别端 + 连接臂"设计提供白蛋白结合与通透性机理的对照参考，以及为后续非骨前临床数据中的通透性信号建模提供文献基线。

### 3.2.3 候选 B — 四环素类：骨结合特性

**骨亲和机制**：四环素类抗生素与钙结合，在活跃矿化与骨重塑区域沉积，可在紫外/紫蓝光激发下产生绿色或黄绿色自体荧光。活骨呈明亮荧光，坏死骨呈低荧光、微弱荧光或无荧光，构成与 ICG 灌注信号互补的骨活性层。

**波段选择**：文献中四环素骨荧光的激发波段包括 390–410 nm 紫光灯、VELscope 400–460 nm 蓝紫光等；本项目工程路线首选 405–460 nm 紫蓝光激发，发射峰值约 529 nm，集中在 500–560 nm。

**文献证据**：四环素类骨荧光在 MRONJ 与感染性骨坏死场景下已有较系统的临床与小前临床证据：

| 文献 | 场景 | 关键结论 |
| --- | --- | --- |
| Pautke 等 2010 | 骨荧光基础 | 系统描述四环素骨荧光在活/死骨的差异化表现 |
| Ristow 等 2017 | 40 名 MRONJ 患者随机可行性研究 | 验证四环素荧光引导手术的可行性与安全性 |
| Ristow 等 2020 | 小型猪前临床 | 在动物模型中评估荧光引导清创的边界判读 |
| 2021 感染性髋关节翻修 | 感染性骨坏死 | 在感染性骨场景下评估四环素荧光辅助判读 |
| 2025 范围综述 | 51 名患者、57 个病灶 | 手术成功率约 89%–100%（仍为小样本综述） |
| MRONJ 荧光引导手术荟萃分析 | 285 名患者、314 个病灶 | 提供相对较大样本的荟萃证据 |

上述证据仍属公开异域解剖/MRONJ 场景，不构成颌骨骨髓炎术中 ICG 目标域证据。

**用药风险与边界**：四环素类作为抗生素存在过敏、妊娠/婴幼儿风险、光敏反应、食管刺激、胃肠道反应、艰难梭菌相关腹泻、严重皮肤反应、颅内高压、肝毒性等已知风险，并存在药物相互作用。为成像目的使用抗生素会引入耐药与微生态风险。文献中报告的剂量（如多西环素 100 mg bid × 7 天）仅作为研究文献证据保留，禁止直接转化为本项目临床用药建议。比赛阶段不开展四环素类研究性人体给药演示。

### 3.2.4 与 ICG 联合使用思路

基于 ICG 灌注层与四环素骨活性层在机理与光谱上的互补性，本项目提出"灌注层 + 骨活性层"的联合判读思路：

- **时序分工**：ICG 静脉注射后约 10 分钟进入 3–5 分钟成像窗口，反映术区实时灌注；四环素类骨荧光为预设给药后骨内沉积信号，与术中实时灌注解耦，可作为骨活性的"历史标记"。
- **光谱分工**：ICG 激发/发射位于 750–830 nm 近红外窗口；四环素骨荧光激发位于 405–460 nm，发射位于 500–560 nm。两个波段在激发源、滤光片与检测窗口上可分离，为双通道叠加提供光谱基础。
- **判读分工**：ICG 高信号提示灌注/通透性升高区，四环素高信号提示活骨区，ICG 低信号且四环素低信号区为可疑死骨/低活性区；两者结合可形成灌注—活性二维判读图，供医生复核使用。
- **Evans blue 路线**：保留为通透性信号建模的文献对照，不与 ICG 同步用于人体给药。

联合使用尚未等同于已验证方案。上述分工仅作为后续工程替代证据与医生复核界面设计的依据，实际人体联合给药需在伦理、药代、毒理与监管批准后开展。

### 3.2.5 新型骨亲和探针模块化设计

在文献候选之外，本项目提出面向颌骨死骨选择性的新型骨亲和近红外探针模块化设计，作为长期研究方向。探针由四个模块组成：

| 模块 | 设计目标 | 候选起点 |
| --- | --- | --- |
| 骨亲和端 | 面向羟基磷灰石结合 | 双膦酸或膦酸基团 |
| 感染识别端 | 区分细菌/生物膜/无菌坏死 | 革兰阳性菌细胞壁/生物膜结合分子为起点，同时设置革兰阴性菌、厌氧菌与无菌坏死对照 |

| 阶段 | 体系 | 终点 | 停止条件 |

### 3.3.2 术中工作距离与放大倍率下的对比度

赛题方显微镜支持工作距离 200–630 mm、放大倍率 1.3×–17×、视场直径 14–190 mm。在不同工作距离与倍率组合下，单位像素对应的物理尺寸差异显著，对造影剂的对比度稳定性提出以下要求：

- **低倍率/大视场**（如 1.3×、视场 190 mm）：用于整体术区概览，要求造影剂信号在低空间频率下具备足够信噪比，避免弱信号被背景淹没；
- **高倍率/小视场**（如 17×、视场 14 mm）：用于边界细节判读，要求信号在局部高对比度区域不饱和，并能保留死骨/活性骨的边界纹理；
- **工作距离变化**（200–630 mm）：照明强度与几何关系变化要求曝光与增益参数可配置，避免在不同距离下出现信号失真。

2026-07-17 与赛题方沟通确认，显微镜可提供原彩图、荧光图、叠加图三路输出，并提供放大倍率与工作距离。上述能力进入后续方案与接口设计时，仍需赛题方补充准确型号、固件版本、倍率/距离读取接口、三路输出的原始性、分辨率、时间戳、帧同步、几何关系、曝光增益与 SDK/采集卡资料；在完成标定、跟踪、配准误差与失效保护验证前，不得声称真实术中导航已就绪。企业设备接入、厂商 SDK、硬件接口、倍率/工作距离实时读取与设备侧驱动适配由企业负责，平台软件保持设备解耦，仅支持官方 JPEG/MP4、三路图像文件及可选标准化元数据进入软件后的分析、医生复核、证据与安全降级。

## 4.2 图像配准与融合

### 4.2.1 传统方法回顾

多模态医学图像配准的传统方法主要分为三类：

| 类别 | 代表方法 | 特点 | 在本场景下的局限 |
| --- | --- | --- | --- |
| 特征点法 | SIFT / SURF / ORB + RANSAC | 对纹理丰富场景鲁棒 | 荧光图像纹理弱、特征点稀疏，常出现匹配失败 |
| 灰度法 | 互信息、归一化互相关（NCC） | 对强度差异较鲁棒 | 计算量大，对大位移敏感，4K 图像耗时高 |
| 频域法 | 相位相关（phase correlation） | 仅估计平移，计算高效 | 仅限平移模型，旋转/形变需另外处理 |
| 简单叠加 | 直接 Alpha 混合 | 实现简单 | 未配准即叠加会产生重影，影响边界判读 |

颌骨骨髓炎术中白光与 ICG 荧光图像的几何关系以小幅平移为主：两通道由同一光路分光获得，旋转与形变近似可忽略。在此前提下，本项目选择相位相关法作为几何配准基线，并在其上构建背景扣除、归一化、伪彩与增强链路，避免直接 Alpha 叠加产生的重影问题。

### 4.2.2 我们的方法：多通道融合链

白光与荧光双通道融合模块实现白光与荧光双通道的十步融合链，默认采用绿色调色板与相位相关平移配准。完整融合链的整体架构如 Fig 4-1 所示，依次包含：文件签名解码、双线性重采样尺寸对齐、百分位背景扣除、相位相关平移配准（含低响应降级）、百分位鲁棒归一化、伪彩映射、Alpha 混合、高斯降噪与 CLAHE 局部对比度增强、ROI 与全图量化、色标与结构化报告输出。

#### 4.2.2.1 结构上的优势

1. **背景扣除先于配准**：百分位基底扣除在配准前进行，可减少荧光通道暗电流与背景散射对相位相关响应的干扰。
2. **配准-归一化解耦**：几何配准与强度归一化分别处理空间与强度域，避免归一化破坏相位相关所需的灰度统计。
3. **伪彩与混合分离**：伪彩映射与 Alpha 混合独立配置，医生可根据术式偏好切换绿色/琥珀/品红调色板而不影响配准与量化结果。
4. **量化-报告一体化**：量化与报告输出在同一调用中完成，输出结构化数据、Markdown 报告、色标图与归一化图，便于证据包归档与复核。

#### 4.2.2.2 性能上的优势

| --- | --- | --- |
| 配准 | 无 | 相位相关平移配准，含低响应降级 |

### 4.2.3 时间强度曲线

对于 MP4 视频流的关键帧序列，平台计算以下指标：

| 指标 | 计算方式 |
| --- | --- |
| 基线校正强度 | 首帧峰值强度减去背景强度 |
| 峰值校正强度 | 序列最大峰值强度减去背景强度 |
| 达峰时间 | 峰值帧相对首帧的时间差 |
| 最大上升斜率 | 归一化曲线相邻点差商最大值 |
| 归一化 AUC | 对基线-峰值归一化曲线积分 |
| 持续时间 | 末帧相对首帧的时间差 |

曲线点经过基线-峰值归一化到 [0, 1]，并显式标注为关键帧采样而非逐帧采集。稀疏关键帧时间强度指标仅作为工程灌注参考，跨病例解释需锁定采集协议与注射方案并由医生复核。

### 4.2.4 融合质量门控与失效保护

相位相关配准中内置三重门控，任一不满足即降级为不配准：

1. **响应门控**：配准响应低于安全阈值表明两通道相关性弱，配准结果不可信；
2. **平移幅度门控**：平移量上限按图像长边比例计算，防止异常大平移破坏图像；
3. **形状可用性门控**：图像最小边过小或两通道形状不一致时直接降级。

降级时返回配准未应用状态并记录原因字段，后续融合链在未配准图像上继续执行，报告中明确标注配准未应用。这种失效保护设计确保融合链在异常输入下仍可输出可用证据，同时通过原因字段提示医生复核时关注配准质量。

### 4.3.4 三路输出质控

三路输出质控模块对原彩图、荧光图、设备叠加图执行三类校验：

| 校验类别 | 指标 | 默认阈值 | 失败状态 |
| --- | --- | --- | --- |
| 时间同步 | 通道间时间戳差 | ≤ 100 ms | 待复核 |
| 几何一致性 | 宽高比相对偏差 | ≤ 2% | 待复核，禁止像素比较 |

# 第 5 章 病灶智能识别与辅助决策模型

## 5.1 模型总体设计

平台软件的"AI 与医生交互判读层"以官方 4K JPEG/MP4 关键帧为统一输入，输出术中可复核的视频信号候选区、风险提示和不确定性区，并通过医生复核回灌形成可追溯闭环。整体设计遵循三条原则：第一，输入边界严格对齐官方技术文档的 4K JPEG/MP4；第二，所有模型输出统一进入四类掩膜输出契约；第三，目标域数据未到位前，模型保持研发验证定位，禁止自动确诊或终判输出。

![Fig 5-1 AI 辅助判读与患者条件安全门](assets/fig_05_01_ai_review_pipeline.png)

*Fig 5-1 模型总体设计。输入层、融合层、双路径推理、四类掩膜输出、医生复核回灌与训练准入形成数据流；患者条件仅通过受限安全门产生差异证据。*

### 5.1.1 任务定位

术中 MP4/JPEG 第一阶段分割任务定位为"暴露骨面门控 + 荧光/灌注信号 + 风险与不确定性提示"的组合，并显式设置疾病终判掩膜不允许、医生复核必需。模型只能输出骨面门控、荧光信号、风险提示和不确定性四类可复核产物，不能直接包装为疾病终判掩膜。

### 5.1.2 主线模型

当前比赛严格主线关键帧分割模型为残差注意力 U-Net 架构，参数量约 40 万，运行阈值 0.4。任务包显式指向该主线，掩膜阈值与最小连通域尺寸均已固化。临床性能声称标记为不允许、目标域标记为否，与医生复核边界保持有效。

### 5.1.3 双路径推理架构

模型总体设计区分两条共享同一模型权重与同一四类掩膜输出契约的推理路径：

- **4K 分块全证据路径**：用于离线关键帧证据生成。输入 3840×2160，分块尺寸 512、重叠 64、共 45 块。3 次重复运行下模型 P50/P95 为 415.683 / 724.432 ms，端到端 P50/P95 为 2181.523 / 5776.683 ms（约 5.78 s），GPU 峰值显存 723.579 MB。该路径落盘概率图、不确定性图、伪彩图、掩膜、风险掩膜、不确定性掩膜与 JPEG 叠加图全部证据。
- **连续帧实时路径**：用于播放同步与摄像头实时分析。前端长边 960、JPEG 质量 0.85、实际 960×720，协议为 CUDA 混合精度 + 关闭测试时增强 + 串行逐帧 + 整帧模式。当前生产模型服务 E2E P50/P95 为 154.685 / 176.457 ms，模型 P50/P95 为 34.368 / 36.377 ms，峰值显存 380.134 MB。快速输出路径不落盘概率图、不确定性图和伪彩图，只保留掩膜、风险掩膜、不确定性掩膜与 JPEG 叠加图，且每帧使用唯一证据路径防止浏览器复用首帧缓存。

两条路径在界面中清楚区分：4K 路径标注为离线关键帧证据生成，连续帧实时路径标注为基于关键帧的播放分析，不得包装成逐帧实时 AI 推理。

## 5.2 多模态融合模型

### 5.2.1 传统基线模型

平台保留了 ConvNeXt U-Net 基线作为研发对照。该模型在锁定代理测试集（公开离体荧光代理）上以单种子运行，Dice 0.8987 ± 0.0000、IoU 0.8164、召回率 0.8908，4K 分块模型 P95 为 800.159 ms，GPU 峰值显存 656.318 MB。基线仅承担"可运行对照"角色，已不再作为比赛严格主线。

此外还评估了多尺度深度可分离 U-Net 作为另一个候选基线：3 种子下 Dice 0.8978 ± 0.0113、IoU 0.8149 ± 0.0183、召回率 0.8933、4K 模型 P95 为 4.25 ms、显存 20.14 MB，参数量约 2.9 万，平均训练损失 0.2974。该候选门控状态为保持，未进入主线。

### 5.2.2 我们的多模态融合模型

**主线架构**：残差注意力 U-Net 在 U-Net 编码器-解码器骨架上引入残差注意力模块，使其在轻量参数（约 40 万）下对荧光信号候选区表现出更稳定的边界敏感度。模型输出经阈值 0.4 二值化后，按最小连通域尺寸 50 做连通域清理，最终输出荧光信号掩膜及派生的边界风险掩膜与不确定性掩膜。平均训练损失为 0.1872。

**双通道扩展（候选）**：白光与荧光早期融合架构已实现，当前运行时未启用，仅作为消融对照保留。

**多掩膜 v2（候选）**：在同一架构上扩展为多掩膜输出，荧光信号阈值与骨面门控阈值均为 0.35。该候选主线替换不允许、运行时审批为可选候选冒烟测试，未通过冒烟测试、边界说明和模型清单复核前不得替换当前 MP4/JPEG 主线配置。

**骨活性多任务 v2（候选）**：基于双编码器（白光 3 通道 + 荧光 1 通道）+ 融合 + U-Net 多头解码器架构，含 4 个输出头：骨面门控头、活性头、分类头、不确定性头。三类骨活性类别为"低活性、过渡、高活性"。该候选仅作为候选保留，运行时替换与主线替换均不允许，当前仅在开发配置中可显式选择，比赛严格配置继续排除该代理候选。

**患者条件分割（候选）**：把年龄、性别、基础病、用药和血液指标参与的临床特征向量并入模型，输出影像基础概率、患者条件概率、差异图与不确定性。当前代理测试集无伤害门失败，运行时强制空间效应不应用、差异掩膜全零，概率回退为影像基础。

1. **同协议多候选可复现对比**：在相同数据清单、来源分组切分、预处理与评价协议下，对三个候选家族完成可复现选型，每个候选均产出配置、模型权重、清单、阈值扫描与中英文对比报告，仅在独立测试集上超过当前主线且通过严格运行门控后才允许申请替换比赛配置。

## 6.2 实验验证

### 6.2.1 荧光造影剂：公开文献与仿真数据

赛题方显微镜 ICG 光学窗口为激发 750–810 nm、发射约 830 nm。本章造影剂验证以"公开文献证据 + 仿真数据 + 工程替代方案"三类来源支撑，未开展实物合成或人体给药演示。

**公开文献证据**：

- ICG 为水溶性三碳菁染料，最大吸收约 800 nm，发射峰约 835 nm，半衰期 3–5 分钟；EAES 2023 共识将组织灌注评估最低剂量定为 2.5–10 mg，推荐 0.25–0.5 mg/kg。
- Naraghi 等 2018 显示 ICG 可显示深部骨感染区域；Goloborodko 等 2024 在 115 例坏死性软组织感染患者中发现存活感染组织均显荧光、坏死组织均无荧光，但该结论未在颌骨骨髓炎大样本中验证。
- Dhiman 等 2022 系统综述覆盖 23 项近红外 ICG 研究、452 例患者；Yoon 等 2019 首次体内验证 ICG 辅助近红外牙科成像可行性。
- 候选 Evans blue（血管通透性示踪）与四环素类（骨结合自体荧光）作为 ICG 之外的第二信号文献路线，详见第 3 章。

**工程数据**：平台软件对白光/ICG 双通道输入执行配准、归一化、伪彩和定量，输出荧光强度曲线、ROI 时序曲线和灌注/活性比值。4K 合成工程验证实例使用 3840×2160 白光 + ICG JPEG，配准响应 0.366592（安全门 0.08），用于核验官方格式尺寸下的输入、融合、ROI 统计和患者条件安全回退链路。公开人体骨移植 ICG 视频用于关键帧时序量化与回放验证。

### 7.1.2 端到端演示闭环

端到端演示闭环以官方 4K JPEG/MP4 为主输入路径，串接以下阶段：

1. 录入脱敏病例并完成批次准入：记录机构授权、脱敏确认、用途范围、SHA256、可解码性、通道关系与同步配对；只有通过准入的文件可登记为病例输入，被隔离的文件仅保留原因码，新准入样本默认标记为"待复核""无标签""训练准入否"。
2. 导入 4K JPEG/MP4，由输入准入服务校验通道关系与同步配对，进入分析流水线。
3. 自动执行配准、归一化、伪彩、融合、质控、ROI 定量；4K JPEG 双通道触发白光/ICG 配对分析，MP4 进入关键帧分割与连续帧快速输出实时叠加。
4. 4K 分块关键帧分割输出骨面门控掩膜、荧光信号掩膜、边界风险掩膜、不确定性掩膜四类掩膜与骨活性连续谱；其中骨面门控掩膜在医生 ROI 或提示辅助复核生成前仅记录为待复核/不可用，不作为骨面真值。
5. 医生复核、人工标注、版本审计、双签晋级；通过或修改的样本进入高权重训练清单，驳回样本默认作为负例或错误分析数据，复核权重按通过 4.0、修改 4.0、驳回 0.5、待复核 1.0 派生。
6. 导出结构化数据 + 量化表格 + Markdown + DICOM SC + ZIP 证据包，含截图、掩膜、量化结果与报告。
7. 三维工作台 L1 静态仿体配准与 L2 离线动态 AR 进入独立前端子页面承载，与病例工作台共享当前病例、关键帧候选区、配准状态、坐标变换、模型来源与医生复核数据。

可重放证据产物位于本机 Git 忽略的运行产物目录下，包含运行配置、四类掩膜、关键帧截图、量化表格与运行日志；按规则不进入版本库，评审可由本机重放命令复现。一键启动入口位于仓库最外层，经严格运行预检与模型预热后拉起前后端，后端在固定端口上提供服务，推理核心由模型预热调用完成预热，并暴露预热接口供前端在启动实时分析前显式触发。

## 7.3 临床应用：说明对传统临床诊疗流程的改进

### 7.3.1 传统流程

颌骨骨髓炎的传统临床诊疗流程通常包含以下阶段：

1. **术前影像**：X 线、CBCT、MRI 用于评估病灶范围与死骨分布，但影像与术中实际情况存在时间差与体位差。
2. **经验性术中判读**：术中由医生依靠肉眼、触诊、术中 X 线判读死骨与活性骨边界，判读高度依赖术者经验。
3. **肉眼/触诊定边界**：清创边界以肉眼可见的死骨颜色、质地与出血情况为主要依据，缺乏可量化的活性边界信号。
4. **清创与序列治疗**：依据上述判读执行清创，术后通过抗生素、序列治疗与影像随访确认效果，复发率与边界判读准确性高度相关。

传统流程的核心痛点包括：影像与术中实时性脱节、死骨与活性骨边界依赖经验、缺乏定量与可复核指标、难以支持术中即时决策。

### 7.3.2 改进后的流程

平台软件在不改变医生最终判读权的前提下，对传统流程进行工程化改造，改进后的流程如下：

1. **术前影像 + 病例准入**：术前 CBCT/STL 通过三维工作台导入并完成批次准入，记录机构授权、脱敏确认、用途范围、SHA256 与通道关系；只有通过准入的文件进入病例档案。
2. **4K 术中视频流**：术中显微镜输出的 4K MP4 视频流（或成对 JPEG）作为一级可见输入方式导入主工作流，原始播放显示在四宫格"视频流输入"视口。
3. **白光/ICG 配准融合**：双通道融合模块完成十步融合链，自动执行配准、归一化、伪彩、融合、质控与 ROI 定量，融合图、热图、归一化图在四宫格输出区呈现。
4. **AI 候选区 + 风险/不确定性提示**：4K 分块关键帧分割与连续帧快速输出实时叠加输出骨面门控掩膜、荧光信号掩膜、边界风险掩膜、不确定性掩膜四类掩膜与骨活性连续谱，作为医生术中参考信号。
5. **医生复核定边界**：医生在人工标注页与复核工作台完成标注、通过、修改或驳回，双签晋级与哈希链审计落地；通过或修改的样本进入高权重训练清单。
6. **证据包回灌**：导出结构化数据 + 量化表格 + Markdown + DICOM SC + ZIP 证据包，回灌至训练清单与多中心验证准备；三维工作台 L1/L2 工程验证作为术中参考延伸。

### 7.3.3 改进点对照

| # | 维度 | 传统流程 | 改进后的流程 | 改进性质 |
|---|---|---|---|---|

## 8.1 创新点

平台软件的创新点按技术层、工程层、临床层三轴组织。每一项创新点均给出可核验承载：输入契约、配置文件、模型权重、清单或报告路径，避免停留在方案描述。

### 8.1.1 技术层

#### （1）候选造影剂组合：ICG 基线 + 多信号互补 + 模块化探针猜想

针对 ICG 仅反映血流灌注、血管通透性与组织活性差异、对颌骨骨髓炎无特异性结合这一文献共识（详见第 3 章），平台软件在不进行实物合成与湿实验验证的前提下，提出可工程核验的候选造影剂组合路线：

- **ICG 基线**：与赛题方显微镜激发 750–810 nm / 发射约 830 nm 光学窗口匹配，作为血流灌注与组织活性参考信号通道；EAES 2023 共识将组织灌注评估最低剂量定为 2.5–10 mg，推荐 0.25–0.5 mg/kg。
- **第二信号候选 A — Evans blue**：基于血管通透性差异示踪机理，作为 ICG 之外的可文献复核互补信号。
- **第二信号候选 B — 四环素类自体荧光猜想**：基于骨结合特性，激发 405–460 nm、发射 500–560 nm，作为骨面/死骨识别的文献研究方向；当前定位为猜想，未做实物合成。
- **新型骨亲和探针模块化设计**：按"骨亲和端 / 感染识别端 / 近红外发光端 / 连接臂"四模块拆分，按 A0–A4 分级实验矩阵组织后续验证路径。
- **工程替代证据**：在 4K 验证病例（67 岁、男、2 型糖尿病、高血压、CRP 32 mg/L）上以白光 + ICG 双通道完成配准、归一化、伪彩、ROI 时序曲线与灌注/活性比值的端到端可核验输出，配准响应 0.366592 远高于 0.08 安全门。

#### （2）多模态融合算法：十步融合链 + 三路质控

白光与荧光双通道融合模块实现十步融合链，全部步骤在源码中可逐行复核：

1. 双通道输入校验与尺寸对齐；
2. 相位相关亚像素配准；
3. 百分位归一化（避免极值压缩）；
4. 伪彩查表生成；
5. Alpha 混合（按质量门动态权重）；
6. CLAHE 局部对比度增强；
7. ROI 提取与时序曲线记录；
8. 质量门标记（配准响应、通道一致性）；
9. 输出契约写入（融合结果 + 三路质控字段）；
10. 失效保护回退（任一门控失败 → 回退模式）。

三路输出质控模块承接赛题方 2026-07-17 确认可提供原彩 / 荧光 / 叠加三路输出的能力，对三路输出执行一致性校验，质量门字段写入证据清单。融合算法在 4K 验证病例上验证双通道成对分析路径，配准响应 0.366592，远高于 0.08 安全门；融合结果、ROI 时序曲线与质量门字段全部进入可核验证据包。

#### （3）多模态 AI 判读模型：残差注意力 U-Net + 骨活性多任务 v2 + 患者条件分割

平台软件主线模型与多任务候选均通过统一适配器接口接入，由统一推理服务调度。三组模型在源码、配置、模型权重、清单与报告中均可核验：

| 模型 | 关键设计 | 工程状态 |
|---|---|---|
| 残差注意力 U-Net（主线） | 残差注意力 U-Net；关键帧主线分割；参数量约 40 万；运行阈值 0.4 | 主线已接入比赛配置；4K 运行门控与连续帧实时运行门控均通过 |
| 骨活性多任务 v2 候选 | 双编码器 + 融合 + U-Net 多头解码器；4 个输出头（低活性 / 过渡 / 高活性 / 忽略区）+ 连续评分头 | 代理域训练完成；工程实用门未通过，未替换主线 |

输出契约统一为四类掩膜：骨面门控掩膜、荧光信号掩膜、边界风险掩膜、不确定性掩膜；其中骨面门控掩膜在医生 ROI 或提示辅助复核生成前仅记录为待复核/不可用，不作为骨面真值。骨活性多任务 v2 在掩膜之上叠加连续骨活性评分（0–1 灰度），形成"候选区 + 边界风险 + 不确定性 + 连续谱"的组合输出。

### 8.1.2 工程层

#### （1）设备解耦与清单接入

平台软件保持设备解耦，只负责官方 JPEG/MP4、三路图像文件及可选标准化元数据进入软件后的分析、医生复核、证据与安全降级。倍率、工作距离、相机标定、坐标变换与位姿记录通过离线清单或人工元数据接入，不依赖企业私有接口。推理运行配置在每个模型项设置设备策略为自动，无 GPU 时仍可工作，仅推理延迟上升。赛题方设备、医院自有设备分别按设备来源、准确型号、固件版本与采集配置独立登记，两类设备的资料、样本、接口与验证结果互不推定。

#### （2）批次准入与样本状态机

输入准入服务与医院准入服务联合实现批次准入流程：

- 文件签名、可解码性、SHA256、重复项、通道关系、同步配对校验；
- 通过 / 隔离 二态准入：只有通过准入的文件可登记为病例输入，被隔离的文件仅保留原因码；
- 新准入样本默认标记为"待复核""无标签""训练准入否"；
- 机构授权、脱敏确认、病例映射保管、用途范围、来源、接收人与时间全部写入清单；
- 医院或医生交接的真实 JPEG/MP4 在写入平台病例、进入分析或形成训练清单前必须完成上述准入。

#### （3）医生复核闭环：双签晋级 + 哈希链审计 + 复核权重

医生复核闭环由复核服务、晋级审批服务与人工标注服务联合承载：

- **身份校验**：晋级审批需可信身份源的角色为医生或项目复核者，强制身份校验通过后才能进入双签流程。
- **追加式哈希链**：按序号、审批 ID、随机数、目标指纹与上一记录哈希写入；随机数唯一约束保证审批记录不可重放。
- **双签晋级**：晋级审批需两名独立具备医生或项目复核者角色的可信身份依次签名方可生效。
- **复核权重**：通过 4.0、修改 4.0、驳回 0.5、待复核 1.0；通过或修改的样本进入高权重训练清单，驳回样本默认作为负例或错误分析数据，待复核保持待复核权重。
- **人工标注页面**：支持从病例 JPEG、MP4 关键帧和模型候选区进入，提供画笔、橡皮擦、多边形、撤销/重做、缩放、标签选择、草稿保存、提交复核与版本历史；后端持久化原图尺寸坐标、像素掩膜、标注类别、医生身份、机构、时间、来源输入、病例、版本、复核状态与训练准入状态。

#### （4）证据包：结构化数据 + 量化表格 + Markdown + DICOM SC + ZIP

导出打包服务联合生成五类格式证据包：

- **结构化数据**：结构化病例元数据、四类掩膜路径、量化指标、复核状态、运行配置、SHA256；
- **量化表格**：量化指标按 ROI / 关键帧 / 时间序列输出，便于二次统计；
- **Markdown**：平台报告生成模块生成可读报告，含平台安全边界与医生复核免责声明；
- **DICOM Secondary Capture**：按 SC 形式构造证据摘要对象，写入病例号与证据摘要描述，承载证据截图与量化结果，定位为证据包扩展，非诊断性 DICOM 输出；
- **ZIP**：上述四类产物按证据包 SHA256 索引打包，写入证据清单。

### 8.1.3 临床层

#### （1）术中实时性：双路径运行门控

平台严格区分"有效帧率"与"采样率"，在两条路径上分别测量并落地门控：

| 路径 | 模型 P95 (ms) | 服务 E2E P95 (ms) | 峰值显存 (MB) | 门控 |
|---|---:|---:|---:|---|
| 4K 分块全证据 | 724.432 | 5776.683（约 5.78 s） | 723.579 | 通过（≤15 s / ≤3 s / ≤2048 MB） |
| 连续帧实时 | 36.377 | 176.457 | 380.134 | 通过 |

4K 分块路径覆盖官方 4K JPEG/MP4 输入下的全证据分析；连续帧实时路径覆盖术中连续帧实时叠加。两条路径共享同一模型权重与同一四类掩膜输出契约，仅分块/平铺与精度配置不同。

#### （2）边界风险提示：边界风险掩膜 + 不确定性掩膜

四类掩膜输出契约中，边界风险掩膜承载边界风险与过渡区决策提示，不确定性掩膜承载低置信或质量受限区。两个掩膜由模型概率图、质量门字段与骨活性多任务候选区联合派生，在界面中以独立图层呈现，明确标注"术中参考信号、非自动确诊"。医生可在人工标注页与复核工作台中对两个掩膜进行修改、驳回或通过，复核结果回灌至训练清单。

#### （3）医生交互判读流程改造

平台软件在不改变医生最终判读权的前提下，对传统术中判读流程进行工程化改造，对照如下：

| 阶段 | 传统流程 | 改进后流程 |
|---|---|---|
| 1 | 术前影像（X 线 / CBCT / MRI） | 术前影像 + 病例准入（批次准入、SHA256、通道关系） |
| 2 | 经验性术中判读（肉眼、触诊、术中 X 线） | 4K 术中视频流进入四宫格"视频流输入"视口 |
| 3 | 肉眼/触诊定边界 | 白光/ICG 配准融合 + 十步融合链 + 三路质控 |

- **多中心数据治理**：在多家医院建立统一的批次准入、脱敏确认、病例映射保管与训练准入流程；所有新准入样本默认保持"待复核""无标签""训练准入否"，直至医生复核及训练准入评估完成。
- **不可声称边界**：在目标域数据、患者级分组验证、概率校准、亚组审计与医生复核门槛通过前，平台软件保持研发验证状态；当前规则派生结果不包装成目标域三分类性能。

## 9.3 概率校准、亚组审计与不确定性提示

### 9.3.1 当前已完成

- **校准指标**：公开 CT 代理测试集 ECE 0.005700，校准良好（但代理域）。
- **不确定性提示**：四类掩膜输出契约中不确定性掩膜承载低置信或质量受限区，边界风险掩膜承载边界风险与过渡区决策提示；两个掩膜由模型概率图、质量门字段与骨活性多任务候选区联合派生。
- **三门门控**：患者条件分割在公开 CT 代理测试集上同时报告无伤害门、亚组门、物理边界门三项独立门控；当前三门均失败，运行时强制空间效应不应用、差异为零、概率回退为影像基础、差异掩膜全零。

### 9.3.2 短期规划

- **目标域概率校准**：在真实目标域样本回灌后，重新评估 ECE、可靠性图与 Brier score；按目标域分布重新校准概率图。
- **亚组审计**：按年龄、性别、基础病、用药、血液指标等亚组分别报告 Dice、IoU、召回率、精确率、ECE；任何亚组 Dice 差异超过预设门控即触发目标域晋级不允许。
- **不确定性提示增强**：在不确定性掩膜之上叠加认知不确定性与偶然不确定性的分解；界面中以独立图层呈现，医生复核时优先关注高不确定区。

### 9.3.3 中期与长期规划

- **多中心概率校准**：在多家医院独立测试集上分别完成概率校准；任何跨中心校准漂移超过预设门控即触发模型重训或域适配。
- **不可声称边界**：在目标域概率校准、亚组审计与多中心验证通过前，平台软件保持目标域晋级不允许、运行时替换不允许、临床声称不允许；当前 ECE 0.005700 仅作为代理域工程证据，不包装成目标域临床校准性能。

## 9.4 三维动态配准与术中实时定位（L3）

### 9.4.1 当前已完成

平台软件按 L0/L1/L2 三层组织三维导航与术中参考：

- **L0 失效回退与坐标契约**：坐标契约模块承载 4 种已知轴约定（DICOM LPS、RAS、仿体 XYZ、OpenCV 相机）；矩阵规范为行优先 + 列向量 + 左乘 + 齐次坐标；任一门控失败 → 导航就绪标记为否、导航级别降为 L0、回退模式为未配准三维参考。
- **L1 静态仿体配准**：静态配准服务联合刚体配准与相机配准模块，采用 Kabsch SVD 与相机位姿求解迭代法；无噪声合成 FRE 1.43e-14 mm、TRE 1.68e-14 mm；公开牙列基准 0.5/1/2 mm 噪声下 TRE 0.352 / 0.772 / 1.625 代理 mm；公开数字下颌仿体 L1 FRE 2.93e-14 mm、TRE 2.34e-14 mm、重投影 6.23e-14 px。
- **L2 离线动态 AR**：离线位姿回放服务联合离线位姿回放模块，采用 PTS 严格递增与恒定帧率校验；9 项安全参数（最大时间偏移 50 ms、漂移阈值 1.0 mm、TRE 代理阈值 2.0 mm 等）；公开 RGB-D 代理 766 帧绑定、2556 位姿、最大时间差 9.693 ms、24 帧受控回放；6/6 帧 L2 软件门通过。

所有 L1/L2 工程结果当前保持导航就绪标记为否、导航声称允许标记为否。

### 9.4.2 短期规划

- **L2 → L3 跃迁准备**：在 L2 离线动态 AR 工程验证基础上，准备 L3 真实术中实时定位的前置条件：坐标配准、误差记录、医生复核、位姿跟踪鲁棒性、失效保护。
- **真实术中数据接入**：在多家医院采集真实术中 ICG 颌骨骨髓炎 MP4 + CBCT 配对数据；按设备来源、准确型号、固件版本与采集配置独立登记。
- **误差记录**：在 L1 FRE / TRE / 重投影 RMSE 基础上，叠加 L3 术中实时位姿误差、漂移误差、时间同步误差；任何误差超过预设门控即触发导航就绪标记为否。

### 9.4.3 中期与长期规划

- **L3 真实术中实时定位**：在坐标配准、误差记录与医生复核齐备后，将导航就绪标记切换为是、导航声称允许标记切换为是；前端三维工作台从"未配准参考"切换为"术中实时参考"。
- **持续验证**：建立周期性 L3 术中实时定位回归测试；任何场景变化（设备更换、术式变化、患者亚组变化）均需重新完成 L1/L2/L3 全链条验证。
- **不可声称边界**：在 L3 真实术中实时定位前置条件齐备前，平台软件保持导航就绪标记为否、导航声称允许标记为否；当前 L1/L2 工程结果不包装成真实术中导航已就绪。

## 9.5 注册合规与产业化路径

### 9.5.1 当前已完成

### 9.5.2 短期规划

- **注册路径评估**：依据国家药品监督管理局《医疗器械分类目录》与《人工智能医用软件产品分类界定指导原则》，评估平台软件的医疗器械分类、注册路径与临床试验要求；当前定位为非诊断性研发验证版平台软件，注册路径待评估。

### 9.5.3 中期与长期规划

- **多中心临床验证**：在多家医院完成真实目标域样本采集、医生复核、概率校准、亚组审计与 L3 术中实时定位验证；建立多中心数据治理与训练准入流程。

- **不可声称边界**：在医疗器械注册、伦理审批、多中心临床验证与企业合作完成前，平台软件保持研发验证版定位；任何对外表述不得包装成已注册的医疗器械、已通过多中心临床验证的产品或已产业化的商用系统。
