# Legacy Research Deliverables

本目录保存早期阶段手工生成或外部交付过的 DOCX/XLSX 资料。它们用于历史追溯和材料复核，不作为当前 Markdown 报告、CSV manifest 或工程配置的唯一事实来源。

当前事实来源优先级：

1. 论文、数据集和视频来源：`research/literature/inventory/*.csv`。
2. 规划与缺口记录：`research/reports/planning/`。
3. 建模、数据来源和实验结果：`research/reports/modeling/`。
4. 预处理记录：`research/reports/preprocessing/`。

本目录文件若与上述 CSV/Markdown 记录冲突，优先以最新 CSV/Markdown 记录为准。
