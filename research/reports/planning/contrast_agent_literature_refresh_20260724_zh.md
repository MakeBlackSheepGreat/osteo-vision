# 造影剂公开文献补强与候选收敛

日期：2026-07-24
范围：颌骨骨髓炎平台的“新型荧光造影剂设计”研究
检索来源：PubMed、Europe PMC 与公开期刊全文；检索关键词覆盖 `bone-targeted near-infrared fluorophore`、`NIR-II bone imaging`、`osteomyelitis fluorescence imaging`、`vancomycin IRDye800CW` 与 `biofilm fluorescence imaging`。

## 1. 官方边界与结论

项目输入规范将“新型荧光造影剂的设计合成、示踪机理、靶向或选择性依据、必要验证数据、显微系统适配性”列为独立研究方向。设备技术资料已确认的 ICG 成像窗口为约 750-810 nm 激发、约 830 nm 发射；其关于近红外二区的表述是“研究热点，可自行参考文献”，未构成现有设备已具备 NIR-II 光源、探测器或滤光片的承诺。

因此，平台材料应采用双轨表达：

1. `NIR-I/800CW` 轨道承担近期可行性和显微镜 A0 适配验证，优先使用已有公开合成和感染识别证据的 Vanco-800CW。
2. `NIR-II` 轨道承担深部骨成像的前瞻创新，优先以 P800SO3-PEG、TTQF-SO3 和 N3-FEP-4T 的骨亲和证据为依据，待设备方确认硬件后进入 A0。

任何候选均未完成本项目的合成、光谱、靶向、湿实验、设备实测、动物安全性或患者研究。外部论文结果只能作为设计依据。

## 3. 候选分层

### 3.1 C0：近期可行性基准

**Vanco-800CW** 作为现有显微镜窗口下的感染识别基准分子。其价值在于已有公开合成路线、IR-Dye800CW 光学参数、革兰阳性细菌/生物膜结合证据以及人源取出器械或人体标本模型的近临床可视化证据。它不具备骨靶向和死骨特异性，平台材料中应定义为“感染识别参考探针”和 A0-A3 对照，不能定义为颌骨骨髓炎的完整解决分子。

### 3.2 C1：NIR-II 骨亲和储备

**P800SO3-PEG** 与 **TTQF-SO3** 是骨亲和与 NIR-II 深部成像的文献锚点。两者可支撑“磺酸化或结构固有骨亲和小分子”的设计逻辑，当前并无颌骨感染特异性证据。只有在企业确认 NIR-II 激发源、探测器量子效率、滤光片、4K 采样与热管理参数后，才进入本项目 A0 光谱验证。

### 3.3 C2：待验证双功能设计

`骨亲和模块 + 革兰阳性识别模块 + 800CW 或 NIR-II 发光模块 + 亲水连接臂` 是可写入方案的模块化研究假设。推荐将其命名为“候选双功能探针架构”，避免使用已经完成合成的语气。万古霉素模块偏向 D-Ala-D-Ala 结构，需设置革兰阴性菌、厌氧菌、无菌炎症、无菌死骨和活骨竞争对照；双膦酸、膦酸或磺酸模块也需检验其对活骨、坏死骨和软组织的相对分布。

## 5. 平台材料写法

1. 把“新型”落实为可检查的候选架构、已知分子模块、文献合成依据和分阶段停机条件。
2. 把 Vanco-800CW 放在感染识别的可行性基准位置，把 P800SO3-PEG/TTQF-SO3 放在 NIR-II 骨亲和的前瞻储备位置。
3. 将“病灶特异性”改写为待检验的多重选择性假设，区分细菌、生物膜、活骨、死骨、无菌炎症和血液背景。
4. 明确官方设备已经确认的 ICG 通道与尚待企业确认的 NIR-II 通道，避免将技术资料中的趋势描述写成设备既有能力。
