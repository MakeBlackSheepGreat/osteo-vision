# 平台输入与设备边界

首次整理：2026-07-03
当前复核：2026-07-19

本记录将设备提供方公开技术资料中的文件格式与成像参数转化为平台可执行的输入契约。原始资料保留在本机忽略路径，仓库只保留非敏感的格式边界和工程约束。

## 已确认输入

| 类别 | 参数 | 软件约束 |
|---|---|---|
| 影像 | `3840x2160` 级别 | 上传、解码、预览、关键帧和推理覆盖高分辨率输入 |
| 文件存储 | USB3.0 介质 | 文件导入作为离线工作流 |
| 图片 | JPEG | 接受 `.jpg` / `.jpeg`，保存来源与质量元数据 |
| 视频 | MP4 | 接受 `.mp4`，执行容器、解码、时序和关键帧检查 |
| 放大倍率 | 约 `1.3x-17x` | 通过离线 manifest 或人工元数据记录 |
| 工作距离 | 约 `200-630 mm` | 通过离线标定表或人工元数据记录 |
| ICG 光学信息 | 激发约 `750-810 nm`，发射约 `830 nm` | 按近红外荧光信号处理 |

## 未纳入软件前置条件的接口

实时视频流协议、厂商 SDK、采集卡接口、倍率或工作距离数字读取、三路输出同步、时间戳、曝光增益和相机标定文件均通过文件元数据或离线 manifest 解耦接入。缺少这些信息时，平台保留文件分析、二维证据和未配准三维参考。

浏览器摄像头、连续帧接口和视频播放同步分析属于平台扩展能力。界面与报告需准确标注“浏览器视频流工程验证”“逐帧连续推理”或“关键帧播放分析”。

## 输入优先级

1. 4K MP4 视频文件。
2. JPEG 图像文件。
3. JPEG 方式下的白光与 ICG 成对分析，可选设备叠加图用于质控。
4. 离线 manifest 或人工元数据：设备来源、倍率、工作距离、时间戳、标定和位姿。
5. 医院 AVI 经过受控转码后的 MP4，并保留原始 AVI、SHA256、编解码参数和映射日志。
6. 研究扩展：PNG/TIFF、DICOM/NIfTI、CBCT/STL、公开数据和标注掩码。

## 平台处理链路

1. 数据准入：授权、脱敏、用途、文件签名、可解码性、SHA256、重复项和隔离原因码。
2. MP4/JPEG 导入：记录分辨率、帧率、时长、文件大小、设备来源和规格匹配状态。
3. 荧光处理：背景扣除、归一化、伪彩、配准、融合、色标、ROI 定量和质量警告。
4. 视频分析：播放同步关键帧分析或浏览器连续帧串行推理；高分辨率关键帧支持 tiling。
5. AI 辅助判读：输出荧光信号、风险、不确定性、候选区、时间稳定性和模型身份。
6. 医生复核：接受、修改、拒绝、待复核、像素标注、版本审计和训练准入。
7. 证据输出：JSON、CSV、Markdown、DICOM Secondary Capture、截图和 ZIP 病例证据包。
8. 三维扩展：CBCT/STL 与离线元数据进入 L0 参考、L1 静态仿体配准或 L2 离线回放安全门。

## 医学与验证边界

- ICG 缺少颌骨骨髓炎特异性，平台仅将其用于灌注、血管通透性和组织活性参考。
- 真实目标域白光/ICG 病例和可信医生像素级金标准仍缺失。
- 公开异域、代理和伪标注指标只支撑工程可行性与模型比较。
- 倍率、工作距离、标定、同步、变换、TRE、漂移和医生复核证据齐备前，三维输出保持未配准参考或离线工程验证。
- 所有候选区、评分和报告需要医生复核，不构成自动诊断、切除边界或真实术中导航结论。
