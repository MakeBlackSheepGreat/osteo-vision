## 4. 性能与复杂度

`tools/benchmark_core_hotpaths.py --repeats 5` 在 Python 3.11.15、NumPy 2.4.6、OpenCV 4.11.0 环境中得到以下结果：

| 热路径 | 参考实现 | 优化实现 | 加速比 | 一致性 |
|---|---:|---:|---:|---|
| 1024 个连通域候选统计 | 562.991 ms | 17.644 ms | `31.91x` | 通过 |
| 3840x2160 全分辨率质量评估 | 347.569 ms | 76.143 ms | `4.56x` | 通过 |
| 10,000 位姿最近邻批量查询 | 113.413 ms | 0.349 ms | `324.87x` | 通过 |
| 1,000 任务记录缓存查询 | 117.573 ms | 20.838 ms | `5.64x` | 通过 |

主要改动：

- 连通域统计使用 OpenCV 原生组件统计，避免 Python 像素级循环。
- 质量评估复用灰度图，使用 uint8 直方图和 OpenCV 通道操作，保留全分辨率指标与原始证据。
- 位姿时间戳预排序后使用二分查询，复杂度由线性扫描降为对数查询。
- 任务注册表按文件签名缓存解析结果，文件变化时自动失效。
- 实时帧减少重复解码、数组复制、无效 TTA 分支和中间文件写入；离线关键帧复用已加载模型。
- 前端显式释放 Three.js 资源、Blob URL、定时器、轮询和可取消请求。

性能报告位于 `artifacts/performance/core_hotpaths_current.json`，字节数 `1,503`，SHA256：

`6ad4b033e8d38ee6f7284b8868ccb6b4253c3448c426173ccf75e7c8ff2def01`

该报告属于本地忽略的运行证据。不同机器的绝对耗时允许变化，输出一致性和相对趋势需要重新核验。

## 5. 实时帧鲁棒性

- 请求体在完整读取前执行容量准入，错误状态保持 400/413/429/503 等合同语义。
- 输入经过文件签名、JPEG 解码、尺寸、病例和捕获时间校验。
- 每帧使用唯一证据路径，生成完成后执行原子目录提交；Windows 目录替换采用 10/25/50/100/200 ms 有界重试。
- 模型产物清理同时校验受管输出根和帧前缀，外部路径不会进入删除范围。
- 每病例默认保留最近 120 帧，可配置范围为 1-1000，淘汰顺序保证保留 manifest 不引用已删除产物。
- MP4 与摄像头连续分析保持单请求串行、超时取消、失败退避和组件卸载取消。
- 150 帧压力回归、实时帧合同测试与完整 Playwright MP4 流程通过。

年龄、性别、基础病、用药和血液指标已经进入临床特征向量、API、持久化、差异证据、前端复核和报告。平台始终保留影像基础结果。当前 `target_domain_promotion_ready=false`、`runtime_replacement_allowed=false`，失败时回退 `image_only_segmentation`。

## 11. 患者安全与已知限制

- 平台输出仅用于术中参考信号、风险提示和医生复核辅助。
- 平台不提供自动确诊、自主切除边界或真实术中导航声明。
- ICG 主要反映灌注、通透性和组织活性差异，当前证据不支持颌骨骨髓炎特异性声明。
- 患者条件分割与骨活性空间模型仍处于非目标域代理工程验证阶段。
- 真实设备全倍率、全工作距离、4K 标定和三路同步关系仍待独立验证。
- 真实下颌仿体物理精度、动态独立测量和真实术中导航性能仍待验证。
- 新型荧光造影剂的实物合成、光谱、选择性、安全性和组织实验仍待完成。
- 部分历史数据清单含生成时的本机绝对 `local_path`，跨机器使用需要读取 `relative_path` 或重建本地清单。

机器可读快照见 `research/reports/release/v0.3.0-rc.2_20260719.json`。任一患者条件、骨活性、标定、同步、坐标、误差、来源或医生复核门控失败时，平台执行影像基线、空间候选不可用或 `L0/unregistered_3d_reference` 回退。
