# 运行稳定性与复杂度收尾审计

日期：2026-07-21
工程基线：`v0.3.0-rc.2` 后的未冻结工作区改动
范围：平台软件的实时视频、L1 静态配准、L2 离线位姿回放与既有核心热路径。

## 结论

当前平台完成一轮以患者安全、证据可追溯和资源有界为约束的代码收尾。改动未扩大医学输出范围；患者条件分割、骨活性空间输出和三维导航继续沿用既有医生复核、安全门控与失败回退。

## 本轮改动

| 路径 | 调整 | 时间/空间效果 | 稳定性与安全语义 |
|---|---|---|---|
| 实时视频分析 | 关键帧、步长、队列、超时、JPEG 质量和帧龄参数统一做有限范围解析；浏览器帧按规范证据路径去重 | 关键帧最多 `8`，队列最多 `8`，避免异常参数造成捕获或推理积压 | 非法、非有限值和越界值回退到安全值并记录告警；重复证据不会重复推理 |
| L2 离线位姿回放 | CSV 写出、最差帧、TRE、漂移、可见点和帧级摘要合并为一次遍历；已核验 PTS 优先复用 `ffprobe` | 写出后对帧序列的 `6` 次额外全量扫描收敛为单次遍历；已核验 PTS 路径避免逐帧 OpenCV 时间戳读取和时间戳列表 | CSV 使用 `.part` 文件后原子替换；异常期间保留既有证据文件，捕获器保证释放 |
| L1 静态配准 | 二进制 STL 使用 NumPy 结构化零拷贝视图；面积校验按 `65,536` 三角形分块 | 保持 `O(n)` 校验边界，移除 Python 逐三角形解包和大规模浮点列表；20,000 三角形微基准 `30.13 ms -> 16.36 ms`，约 `1.84x` | 保留 float64 面积阈值、非有限值与退化三角形错误码、模型校验和未配准回退 |
| 既有核心热路径复核 | 连通域、4K 质量、位姿最近邻和任务注册表缓存重新执行一致性基准 | 本机本轮结果为 `25.53x`、`3.26x`、`290.05x`、`4.76x` 相对加速 | 四项输出一致性均通过；4K 质量仍保留全分辨率证据 |

绝对耗时受硬件与运行负载影响。所有加速比仅用于本机工程回归和趋势核验。

## 保持的医学边界

- 实时视频输出仍为 `video_signal_segmentation` 研发验证结果，供医生复核。
- 患者条件分割和骨活性代理模型继续保持影像基础结果与空间替换关闭状态。
- L1/L2 的来源、坐标、标定、同步、误差或复核任一门控失败时，平台维持 `L0/unregistered_3d_reference`。
- 本轮工程验证不产生目标域临床性能、切除范围或真实术中导航结论。
