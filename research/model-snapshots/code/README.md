## 使用边界

- 本项目实现通过适配层引用思路或依赖包，避免直接修改快照形成隐式分叉。
- 引入代码前记录上游 URL、commit/tag、许可、文件清单和修改说明。
- 第三方测试、文档链接、Python 版本和依赖约束不代表本项目当前质量状态。
- 快照中的断链、旧命令和上游历史术语按第三方原文保留。
- 模型进入运行配置前需提供可运行结构、训练或推理 adapter、checkpoint manifest、最小测试、数据边界和运行许可。
- 临床性能声明需由本项目目标域数据、独立验证和医生复核证据支持。
